# EchoSpeak for Windows

EchoSpeak's Windows app uses the same chat, voice, research, projects and Creations
experience as the web interface, inside a native desktop window.

Download the app from the [official releases](https://github.com/Ty0x7/EchoSpeak/releases/latest).
The [user guide](../../docs/GUIDE.md) covers installation, first-time setup, models,
voice and everyday use. Available updates appear above Settings.

The desktop app starts its backend in the background, keeps user data separate from
the installation, and checks updates before installing them. Standard shortcuts are
maintained during installation. Independently saved copies may need to be removed
from the taskbar and replaced with the current app's pin.

If Windows reports a threat, stop and check Windows Security's Protection history.
Report the app version and threat name through [GitHub issues](https://github.com/Ty0x7/EchoSpeak/issues).
Do not include credentials or private conversations.

For the system design, see [Architecture](../../docs/ARCHITECTURE.md).
