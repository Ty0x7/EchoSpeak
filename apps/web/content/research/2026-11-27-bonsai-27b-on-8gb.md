**Ternary Bonsai 2.5 27B** stores its weights as −1, 0 or +1 with shared scales: about **1.76 bits per weight** and
5.99 GB on disk. We tested whether that makes a 27B model practical on an 8 GB graphics card, inside EchoSpeak, against
our 9B reference model (Qwen 3.5 9B).

## What it took to fit

::figure vram-budget

- **32K of context fits only with a 4-bit cache.** A 16-bit cache runs out of memory, and so does 8-bit above 16K. We
  use the calibration ("mean-centering") its authors provide to reduce the 4-bit cache's error.
- **The desktop is part of the budget.** At 1.0–1.35 GB of desktop graphics memory, the default processing batch
  crashed on the first request; a smaller batch (256) fixed it at no measured speed cost.
- **Larger windows:** at the tested settings, 40K and above exceeded the card's capacity with the cache on the GPU.
  We allocated 64K using system memory for the cache and measured about 5–13 tokens per second.
- **Sharing the card:** the model server can release GPU memory on a switch or after two idle minutes. The next
  request may have to wait for the model to reload.

## What it did

The matched comparison used the same harness and judge on 59 tasks, with two runs per task.

::figure bonsai-vs-qwen

| | Qwen 3.5 9B | Bonsai 2.5 27B |
|---|---:|---:|
| Judge score (out of 10) | 8.77 | **9.25** |
| Held-out tasks | 8.71 | **9.25** |
| Flagged unsupported claims across both configurations | 9 of 177 runs | 1 of 177, disputed |
| Agent tasks completed | 69% | **96%** |
| Screenshot questions answered correctly | 15 of 18 | **18 of 18** |
| Generation speed | 17–21 tokens/s | **44–50 tokens/s** |
| Median task time | **41 s** | 50 s |

## The trade-off

Bonsai writes tokens 2.6 times faster but thinks 4–5 times longer, so a **typical** task takes longer. The slowest
tasks were faster, because it needs fewer attempts. A combined score we fixed before testing (60% quality, 20% median
speed, 10% context, 10% stability) still slightly favoured the smaller model: 8.71 against 8.67.

::figure efficiency

In the matched runs, the portable outcome scorecard counted **12.4 successful tasks per million tokens** for
Bonsai and **6.5** for Qwen. The rates per hour of task time were **26.2** and **20.5**, respectively.

## Limits

These results come from one RTX 3060 Ti workstation with 16 GB of system RAM. The card had little graphics memory
to spare and ran near its power limit under load. The 64K run checked recall, so its wider agent performance is open.
