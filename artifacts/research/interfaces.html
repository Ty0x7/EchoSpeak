The launcher points into the local main checkout. Pulling updates those source files. Reopen the client and restart the shared backend to load changed Python code.

Apps-menu desktop

The launcher opens an AppImage: a packaged copy. Build and replace it to update its bundled code. A Git push or pull does not change an existing package.
