16 November 2026 · research for review · update: C1–C5 fixed, each with a regression test (see the technical record) · branch five-model-harness · technical record: docs/research/harness-execution-reliability.md

Proposed turn lifecycle

Blue boxes are proposed changes; the rest exists today. The model proposes, the harness decides, and only checked effects count as progress. After a crash, a turn resumes from its last completed step, never by re-running an effect whose outcome is unknown.

Defects confirmed in the code

Each was read in the code; the first two were re-read by hand. They are independent of the model in use.

C1

MCP failures recorded as success

A transport error or timeout comes back as a JSON string with isError. The success test checks only dicts and prose prefixes, so the action is recorded completed, and a real retry is then refused. mcp_client.py:498, toolbox.py:930

C2

Parallel reads skip approval and jump the queue

Two or more read-only calls run in a pool before the step's other calls, and that path never calls _approve. An "ask" decision is recorded but not enforced. loop.py:959-975, :1329

C3

Stop doesn't stop running work

A foreground command ignores cancel for up to 900 s. Background processes survive Stop and "stop everything", and are lost track of after a crash. terminal.py:924, api/server.py:323

C4 · C5

Unapproved tool changes; unredacted arguments

An MCP list_changed re-registers tools without the trust check. Tool arguments reach the journal and state.db unredacted. mcp_client.py:699, loop.py:1552

Already strong, and kept

kept

Claims vs evidence

The Verification Ledger and the final-reply checks hold "done" against what commands actually showed. This is stricter than any framework surveyed.

kept

Intent → result → unknown

The work ledger records intent before effects, marks the in-between as unknown, and requires reconciliation. This is the pattern LangGraph and OpenAI document as best practice.

kept

Scripted model tests

ScriptedClient already drives about 20 test files. It needs fault injection (V7), not replacing.
