One learner, three environments

ChatLearns from grounded research, your corrections and feedback. No coding loops and no extra model calls. Now reads the lessons it's credited with; before, they were counted but never shown.
AgentsLearns from tool results, finished and failed tasks, delegation and research. Echo here and in Code is the same learner.
CodeLearns from tests, builds, errors and benchmarks through the 11.11.5 verification ledger. Lessons can be scoped to one project.

All three go through the same harness hooks and the same store. Personal memory is separate, and so are external Codex, Claude Code and ACP sessions.

Bounded: reviews only when no chat is running, 30 a day, with each agent's own model, most informative first. No lessons for small talk; at most 900 characters of them (420 for a small model). Twins are merged without a model call. Nothing here adds a model call to your conversation.

Your next message is feedback

Counted

"That worked, thanks!" worked
"It still doesn't work" didn't work
"You misunderstood, I meant the CSV" misunderstood, so the lessons aren't blamed

Ignored

"Let me see if it works"
"Does it work?"
"No thanks"

No model call. Applied to the reply you're answering (the lead agent's), only from the start of your message, and never over the buttons. A casual "that worked" is noted but isn't proof; the checks still decide.

Sharing what's proven, carefully

Agent

The default. Echo's lessons serve it in both Agents and Code.

Project

"In this project, run the linter first." Read only in that project.

Shared

A proven, trusted lesson can be offered to another agent for the same kind of task, one per prompt. Like every lesson, it's sometimes held back at random, so its effect there is measured against a control. If tasks go better without it, it stops being shared, but keeps its place at home.

What you see

Before

A Learning page in the navigation, review queues, and settings for reviews per day and lessons per task.

Now

Nothing in the navigation. Settings › Memory has one switch. Settings › Advanced › Learning holds the diagnostics: what was learned and whether it helps, the rare lessons needing review, pause per agent, and Reset learning (memory untouched).
