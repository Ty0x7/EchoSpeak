What the recorded runs showed, and what changed

Found liveFixed · tested

The window EchoSpeak assumed wasn't the one served

Assumed 32,768; Ollama served 16,384. A 43,104-token prompt came back HTTP 200 as 8,194 tokens: first 4 kept, system prompt and rules gone. Now the served window is read from /api/ps, a cut prompt is detected from the server's count, its reply is discarded and its tool calls never run. (Audit F06.)

Found liveFixed · tested

Answers written only as reasoning

31% of calls ended with nothing; the user saw "I couldn't put together a reply" though the model had found the answer. Replays: re-asking gave 4/4 empty, thinking off gave 4/4 answers. Now one thinking-off retry from the reasoning.

Found liveFixed · tested

Deleting work without a card

Overwrite-to-empty ran without approval; after rm was denied the model wrote the file empty instead. Now emptying or gutting a file asks, and a refused file can't be changed another way without asking (no grant or autonomy covers it).

Found liveFixed · tested

Compaction that never worked

Every summary call spent its budget thinking and returned nothing, retried each step (37 times in one run), uncharged. Now thinking off, charged, gives up after two failures; 16k windows keep room for the work.

Found liveFixed · tested

Checks that checked nothing

Missing pytest reported as a failing test (a loss for learning); pip install pytest counted as a test; pytest || true "passed". Now environment, not a check, and not evidence. "The test passes" with no test run is sent back.

Found liveFixed · tested

Streams that ended early

In 4 of 84 turns the client got journal_done mid-answer while the journal held the rest. A read-then-status race; the reader now reads once more after the run finishes. The test fails on the old code exactly as live.

Also: fresh-token accounting after a trim counts what was added, not zero (audit F09). 27 new regression tests; 525 passed across the related suites on the final code.
