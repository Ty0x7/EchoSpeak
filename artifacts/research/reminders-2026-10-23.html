Reminders and the system tray

23 Oct 2026 · EchoSpeak 11.10.2 · built on Routines · technical record in docs/research/reminders-2026-10-23.md

1 · From "remind me Sunday" to a notification

What Echo gets back from set_reminder
Reminder set (r-3f2a9c1d): "Raptors vs Timberwolves at 5 PM" · Sunday, October 25, 2026 at 4:00 PM (in 2 days).
It will appear in this chat and a Windows notification. If EchoSpeak is closed then, it arrives as soon as EchoSpeak starts again.

Example tool output from the tests. Repeating reminders read like "every Sunday at 4:00 PM". A reminder can also carry a task ("check the final score"): Echo does it at that time, unattended, and skips anything that needs your approval.

2 · Keep running in the tray

Settings › General › Keep running in the tray when closed, off by default and shown only in the desktop app. The desktop shell follows the setting within seconds. Turning it off while the window is hidden brings the window back, so it can't be lost. Launching EchoSpeak again also reopens it.

3 · What keeps it safe and reliable

no model needed

Plain reminders post themselves

They work even when LM Studio is closed. Only a reminder with a task runs the agent.

never interrupts

Waits for a busy chat

If Echo is mid-reply in that chat, the reminder waits a minute. Under Stop everything it waits until you resume.

Rule of Two

No planted tasks

A reminder with a task, set after reading web or app content, asks you first. Only owners can set reminders, and a routine can't schedule more.

Limitations: reminders need EchoSpeak running (tray mode keeps it running when the window is closed, but not through a shutdown, and there's no start-with-Windows yet). They can be up to a minute late. Clicking a notification doesn't jump to its chat.
