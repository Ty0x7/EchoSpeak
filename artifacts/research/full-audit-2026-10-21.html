3 · The biggest open risk: Auto terminal falls back to this PC

A denylist can't tell what a script will do from its name. Codex and Claude Code use OS sandboxes for this: Codex ships a native Windows sandbox, and Claude Code points native Windows users to WSL2. This needs your decision, so it wasn't changed:

option

Ask on fallback

When the sandbox isn't available, every command on this PC asks first. Safest, and noisier.

option

Explicit choice

Auto never falls back silently. The owner picks "this PC" once, and the agent is told which one is in use.

research

WSL2 or OS sandbox

Use WSL2 as the sandbox, or Windows restricted tokens and ACLs. Most work, and the only real fix.

4 · Checked and holding

holds

Desktop API

A random key per launch, no localhost bypass, proxy headers ignored. No HTTP route runs a tool outside the loop.

holds

Who's asking

A2A inbound and Twitch/Twitter resolve to public look-up tools. Unknown sources fail closed. Approvals and autonomy are app-only.

holds

Frames and views

Artifacts have no network. MCP App views reach only declared https/wss origins and call only read-only tools of their own server.

holds

Paths

/work/… mapping can't escape the folder: three .. forms were refused.

holds

History and loops

History is rebuilt as text, so no orphaned tool calls. Per-turn signature counts catch A/B/A/B loops.

holds

Privacy and OAuth

Private and Offline hold through the socket backstop. MCP OAuth passes iss for RFC 9207 checks.
