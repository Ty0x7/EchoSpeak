Five paths, decided by the model, checked by the app

You askWhat happensTrace
"What's the capital of France?"One model call, no toolsdirect · 1 step
"When does version 5 come out?"Search → read the best page → answer linking itsearch · 3 steps · cited: the page read
"Is product X worth buying?"2 searches, 2 pages read; an invented link is caught and replaced with the pages actually readresearch · 6 steps · 1 correction · unknown links: 0
"Does it include offline mode?" (follow-up)No new search: memories, the chat summary and the pages read earlier are in context and citabledirect · cited: an earlier page
"What does src/math.py do?"Read the file, then explain what's actually therefiles · 2 steps

No keyword router picks the path. As in OpenAI's documented tool_choice: auto, the model decides. Chat bounds it (allowlist and budget) and checks the result (evidence).

A tool result isn't the answer: evidence and citations

Read

The page was opened and read this turn (or earlier in this chat). The strongest citation.

Seen only

It appeared in search results but was never opened. Allowed, and traced as weaker.

Unknown

Nothing retrieved it, so it's likely invented. After research, Chat is asked once to replace or remove it.

An answer that read pages but cites none of them is asked once to cite them. Links in an answer that did no research are left alone (and traced), because citing well-known documentation from knowledge is normal.

StableIdentity, rules, formatting, capabilities, environment: the same every turn
This chatYour facts, the chat summary, pages read earlier, past chats when you point back
The turnThe last 30 messages verbatim; older tool output trimmed as the context fills
ClockLast, so the cached prefix survives the minute changing

Small local models (about 9B or fewer) get the same contract in fewer words, a shorter tool list and 6 steps; larger and API models get the full Chat instructions and 10 steps.

Verified, approximated or limited by the model

Verified by tests

Loop and budget fallback, Chat guard, evidence ledger, citation audit and correction, profiles, prompt order, earlier sources, saved trace.

Approximated

Citations are audited links, not offset annotations. Compaction is a local summary, not provider compaction items. find-in-page is notebook reading.

Model-limited

When evidence is enough, how well queries are refined, how contradictions are weighed. Your live test decides how close it feels to ChatGPT.
