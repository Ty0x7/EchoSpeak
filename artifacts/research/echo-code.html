Original harnesses inside Echo Code Implemented · fixture verified

Choose Codex, Claude Agent or a compatible ACP agent. Each uses its own native session and tools in a separate Git worktree. Echo displays streamed output and permission requests without routing the task through an Echo model.

Separate authority, visible changes

  • Codex: official app-server, official account sign-in, persistent native threads and model catalog.
  • Claude Agent: official SDK, explicit API authentication, original tool presets and every-tool approval hook.
  • ACP v1: owner-selected executable, native tools, exact permission option IDs and honest capability negotiation.
  • Worktrees: no automatic source edits, merges or copying of dirty owner files.

Worktrees separate cooperative edits. A trusted executable still runs with the owner's OS authority. Command approval may authorize access beyond the worktree.

Rollback without stale agent history

Stop the runtime first. Echo checks file, index and HEAD fingerprints, retains a recovery copy, and refuses newer edits. After restoration, the session is retired so the original conversation cannot resume against different files.

Verification boundary

Local Git/protocol fixtures, native SDK API checks and installed Codex schema validation establish the implementation. Real login, paid inference, chosen ACP interoperability and installed signed Windows acceptance remain pending.
