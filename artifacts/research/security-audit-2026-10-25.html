Keep authority at the existing boundaries

Echo Code creates native coding sessions through Echo's existing session stores and transport. External agent choices are passive discovery only. The security changes harden the shared backend, build pipeline and updater.

Architecture diagram drawn from current source. It does not claim that prompt injection or host execution is fully contained.

Build and test locally

The source now targets 11.10.5. The new signed build requires the owner's signing-key password in local PowerShell. The completed package results below describe the initial 11.10.3 development build.

Fresh NSIS EXE and MSI bundles built successfully. The EXE is 162.92 MiB and has no Windows publisher signature. Neither bundle was installed or published. Hashes are in the verification record.

Run from the EchoSpeak checkout in PowerShell. The build uses the existing locked backend environment and produces the NSIS installer.

& .\apps\desktop\scripts\release-windows.ps1
& .\release\v11.10.5\EchoSpeak_11.10.5_x64-setup.exe

After installation, open Echo Code, attach a trusted project, choose Echo native, create a session, and select your model in the composer. Check model search/favorites, reasoning selection and ordinary Chat as well.
