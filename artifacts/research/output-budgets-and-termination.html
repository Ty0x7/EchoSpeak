The video's claims, against our own evidence

rare here

"Never finishes thinking"

15–45% of modified 27B builds in the cited benchmark. Here: 1 in about 600 calls for the Heretic model. Its blank replies (7%) stop normally with the answer inside the reasoning, which the harness already recovers.

new failure

A tool call the server couldn't read

Ollama rejected a malformed call yet answered HTTP 200 with no call and no finish. The harness took it for a blank, and the model then claimed an edit it never made. It is now marked incomplete and asked again correctly.

mislabelled

The window, not the output limit

Prompt 8,525 + reply 7,859 = 16,384: the served window filled, below the 8,192 max_tokens. Blank replies now carry the real cause.

confirmed

Weights fit, the machine didn't

Gemma 12B is 98% on the GPU, but llama-server's 8 GiB host prompt cache grew its runner to 12 GB and the job was stopped. A fresh load uses 2–3 GB.
