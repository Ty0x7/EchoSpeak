What all three share

One loop

Tool calling, steering, cancellation, compaction and saved long outputs.

One safety model

Permissions, approvals, policy, checkpoints and project isolation.

One learning system

Episodes, lessons with holdouts, and measured transfer between learners.

Codex, Claude Code and ACP sessions keep their own loops, models and sign-ins. Nothing in them changed.
