Context, memory and long conversations · qwen3.5:9b on this machine

19 November 2026 · branch tui-refine · technical record: docs/research/context-strategy.md · script: apps/backend/scripts/context_probe.py

Keep 16K. A larger window doesn't buy recall this model already has; on an 8 GB card it buys slower replies. The bigger win was in EchoSpeak itself: the prompt layout made the server reprocess the tools and the whole history every turn. That is fixed: 5.73 s → 0.31 s before the first token of a second turn at 13K tokens.

What a larger window costs here (measured)

RTX 3060 Ti 8 GB · Ollama 0.40.16 · flash attention · q8_0 KV cache. qwen3.5:9b is hybrid: only 8 of 32 layers keep a KV cache (16 KiB per token at q8_0: 256 MiB at 16K, 1 GiB at 64K). Ollama holds ~5.6 GB of this card for the model; a bigger window moves more of the model onto the CPU.

The prompt layout fix

llama.cpp reuses the unchanged start of the previous prompt (9.4K tokens: 4.09 s → 0.31 s). EchoSpeak ended its system prompt with the time to the minute, and the system prompt comes before the tools and the whole history, so every new minute meant reprocessing all of it. The time (and git status) now ride on the current request.

How EchoSpeak stays inside 16K

History

Last 30 messages verbatim; older turns as a per-chat summary. Tool outputs aren't carried across turns, only replies.

Within a turn

Older steps summarised (≤ 200 words) and trimmed when the window fills; big outputs saved behind out-… IDs and reread with read_output.

Memory

Retrieved per request (top 8), with memory_search and chat_search on demand. Next: move per-request recall out of the system prompt too.

Agent awareness, from the owner's session

Guessed IDs, corrected with facts

The model called read_output with invented IDs, then made 76 more calls. A wrong ID now gets this chat's real saved outputs (or "none").

The right tool, from the request

"look at codex and claude sessions" never reached agent_sessions. Strong, distinctive matches between a request and a hidden tool now list it up front: across 52 evaluation prompts, only the two session questions gain a tool.

Single runs on this machine; reproduce with context_probe.py (≈ 90 s, unloads the model). Not measured: multi-fact reasoning at depth, a text-only build without the vision projector, num_gpu overrides.
