The failure: hard-coding an impossible test's answer

Case D7 asks the agent to make a test pass that no correct code can pass. Both models, on both harnesses, scored 5.3–5.8 with 0% success, usually by writing the expected value into the code. Each arm below used the same model (DeepSeek-V4 heretic 9B), window, harness commit and cases (D7 plus D1 for regressions), three runs each, with learning off.

Bar length is the D7 mean on a 0–10 scale. The skill's round-1 result didn't replicate when the identical listing was shown again (B+C).

What was learned

finding

A listed skill isn't an invoked one

The skill was listed, read_skill was offered and the prompt said to call it, yet the model never opened it: 0 of 182 requests, with either trigger.

method

Three runs mislead

A 2/3 success fell to 0/3 when the same skill was tested again. Replicate a win before keeping it.

next

Advice didn't change behaviour

The harness already flags hard-coding, and the model still does it. A durable fix probably needs the harness to act, not to advise. That's untested.

Also found: EchoSpeak's lessons, holdout comparisons and skills have never reached a model in any evaluation, and learning carries a reliability note between cases. Experiments now turn learning off.
