Discover and approve new connections

Echo can suggest app integrations from setup guides and the MCP registry. The owner approves each connection, then a read-only call checks readiness; group work can continue while making progress.

What changed

What's new

  • Echo finds a way into new apps.
  • You approve every connection. Suggestions wait in Settings › Advanced › Connections & skills, under MCP servers.
  • Echo checks that it works. After you approve, Echo can see whether a connection is running, what went wrong if it isn't (not installed, app not open, first start still downloading, key refused) and how to fix it.
  • Big apps don't crowd the chat.
  • Group work runs until it's done.

Fixes

  • Token use in group jobs now counts what each step adds.
  • MCP servers that need start-up arguments from the registry now start correctly.
  • Results that servers send twice (as text and as structured data) reach the model once.
  • An MCP server's tool labels are now part of its approval, so changing them needs your OK again.
Setup and compatibility
Same as 11.5.1. Each connection lists its own needs (often Node.js or uv, and the app itself). Notion, Linear and Jira's official servers need browser sign-in, which isn't supported yet.
Verification recorded at the time
- Backend tests, including new suites for connections and an end-to-end approval of a real local MCP server. - Frontend type checks and unit tests. - Live searches of the official MCP registry.
