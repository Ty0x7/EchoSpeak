What changed

Search

  • EmbeddingGemma-300M (4-bit, about 220 MB) as the Better option: 100+ languages, 2K-token inputs instead of 256.
  • LM Studio's embedding models listed by name. Qwen3-Embedding-0.6B is suggested for the best quality.
  • Sharper results for English documents: a 24 MB reranker that now runs in the installed app.
  • Fixed: uploading a document with document search on failed.

Reliability

  • Screenshots list the buttons Windows names, at exact points to click.
  • Every click reports how much of the screen changed; "No visible change on screen" when it missed.
  • A file Echo says it wrote must exist on disk.
  • One recorded outcome per action, read by learning and the safety checks.

Safety and control

  • Blocked apps are refused from the terminal too.
  • Commands on this PC ask when the Docker sandbox isn't running.
  • "On this PC" means this PC.

Research workers

  • Only for deep research or on Ultra effort.
  • All at once by default; Settings has Workers one at a time.

Verification and limits

The backend suite and the web typecheck and tests pass. The new search models ran on their real files on this PC: the multilingual model matched an English and a Spanish note to the same question and found code for a code question, and the reranker put the relevant passage first. The reranker reads English only, and its switch says so. Live model sessions and the packaged app remain owner testing.
