What changed

  • Each chat owns its live transcript and event queue.
  • Return to a running chat to see its latest progress.
  • Explicit Stop still targets the selected chat.
  • Markdown data tables use a real full-width table, properly padded cells and readable minimum column widths.
  • Creations uses the shared sidebar page cards, empty/loading states, typography and controls.
Verification recorded at the time
TypeScript checks and 14 focused frontend tests passed. A browser check with controlled model streams covered two simultaneous chats, tokens received while hidden, switching back during a run, sidebar-page navigation, hidden completion, and no cancellation or cross-chat output. The two reported table examples were rendered and inspected at wide and narrow widths, along with the Creations empty state. The production frontend build passed. Live model/account testing and Windows installer signing remain part of the user testing handoff. This update does not introduce a new research-notebook screen.
