What changed

Harness improvements included from 11.8

  • ElevenLabs read aloud. Choose a voice in Settings, play a sample and use it for reply playback and supported voice conversations.
  • Computer control. Compatible Claude models can use their native computer tool through EchoSpeak's checked executor.
  • MCP sign-in, views and long tasks.
  • Safer outside content and better diagnostics.
  • Pinned remote agents. Owner-approved signed Agent Cards and brokered credentials support the existing outbound A2A tool.
  • Smaller dependency surface. Tools, memory search and document search use EchoSpeak's own implementations.
  • Release evaluation. The Echo bench is included for owner-run real-model evaluation.

Project workspaces

  • Open a project to browse its reports, files, conversations, saved research, artifacts, media, routines and activity in one place.
  • Keep named Markdown or HTML reports with revisions, related files and images, source-agent details, reported checks and remaining work.
  • Echo can read the bound project's workspace and save a report through native tools.
  • Existing project records and artifact history provide storage.

Optional sharing with coding agents

  • Enable sharing on an attached project to prepare a local .echospeak handoff folder.
  • Stable report IDs and increasing revisions prevent duplicate imports and stale overwrites.
  • Explicitly export the project brief, saved research and bounded workspace context for other authorized agents to read.
  • Optional hooks can record that an agent turn ended or failed.

Computer control carried forward

  • Screenshots reach vision-capable models as image inputs and appear in chat, with original-image viewing through the shared panel.
  • Bounded desktop controls include clicks, typing, shortcuts, dragging, scrolling, relative mouse movement and brief simultaneous key/button holds, followed by a new capture.
  • Clearer Desktop toolset and allowed-application guidance, Windows Store app resolution and saved desktop shortcuts improve app-launch recovery.
  • A chat-wide screen-control approval supports continued screen-guided work.
