What changed

  • The installer and uninstaller use the current Echo icon.
  • The app no longer launches PowerShell to rewrite shortcuts on every startup.
  • Approved Windows terminal commands respect the host's PowerShell execution policy.
  • Updater signatures are verified before publishing.
  • Public guides focus on setup and everyday use.
  • Installation guidance no longer tells users to bypass Windows warnings.
