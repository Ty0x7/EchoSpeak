Harden the existing trust boundaries

Host commands after outside content require approval. Child processes lose inherited app secrets, file scope is tighter, and memory indexes gain integrity checks.

Conceptual update flow.

What changed

What's fixed

  • Commands after reading the web always ask first.
  • More risky commands ask first.
  • Your keys stay with EchoSpeak.
  • Agents can't touch EchoSpeak's own settings.
  • Memory files can't be swapped out.
  • Stronger protection against pages pretending to be EchoSpeak.
  • File access stays inside your project.
  • Memory clean-up stays out of the way.
  • Math in answers uses the patched KaTeX everywhere in the app.
Setup and compatibility
Same as 11.5.0. No data migration. Memory and document search files from earlier releases are trusted once and protected from then on.

- Backend tests, including a new hardening suite for every fix above. - Frontend type checks, unit tests and the production build; npm audit reports no issues. - 16 desktop contract tests.
