What changed

What's new

  • Work together. The old "Discussion" group mode is now Work together.
  • It stops for a reason, and tells you.
  • Echo can update its own personality, for real.
  • No more made-up "I saved it". If an agent says it saved, sent or remembered something but didn't actually do it, it is asked to do it or correct itself, and you see a "Not verified" note if it doesn't.

Better at the terminal

  • Long builds and installs are no longer cut off at the time limit: they keep running in the background and the agent checks on them.
  • Dev servers (npm run dev, vite, python -m http.server, …) start in the background in seconds instead of blocking for two minutes.
  • Commands never hang waiting for typing.
  • Errors are clearer ("that program isn't installed", "use ; instead of && in PowerShell"), and files changed by a command can be undone like any other edit.

Smarter context

  • Teammates remember what matters for their task and know what the chat has been about.
  • Say "like last time" or "what we talked about yesterday" and Echo pulls up the matching past conversation by itself.
  • Long tasks get a regular "are you still on track?" reminder, so agents change approach instead of repeating failing steps.
  • Agents carry fewer, clearer tools (Glados no longer gets shopping and stock tools).

Chat scrolling

  • At the bottom, the chat follows every new message, including fast group runs.
  • Scroll up and it stays exactly where you are while agents keep talking.
Setup and compatibility
Same as 10.0.0. No new settings. Your agents' tool settings are updated once on first start. Full technical notes: CHANGES.md and docs/research/harness-review.md.
