What changed

When something goes wrong

  • Agents ask instead of giving up.
  • Errors say what to do next. If web search fails, the agent hears why and what to try: another route first, then asking you.
  • A system check. Settings › System check shows whether web search, page reading, the model, speech to text and memory search are working, and how to fix what isn't.
  • A check before "done". When an agent changes code, it runs the code or its tests before saying it's finished, or tells you plainly that it couldn't check.

Staying in charge

  • Stop everything. One button at the bottom of the sidebar (click it twice) cancels every running agent and pauses routines, Discord and Telegram replies, and outside agents until you press Resume.
  • Limits on outgoing messages. Agents can send at most 5 messages a minute and 30 an hour on each channel (email, Discord, Telegram and so on), so a confused agent can't spam your contacts.
  • MCP servers wait for your OK. A new or edited MCP server doesn't start until you approve it in Settings › Advanced › Connections & skills, and if an approved server changes its tools, they stay off until you approve again.

Skills

  • Agent Skills. Settings › Skills imports skills in the open SKILL.md format: from a folder, or by pasting one.
  • Lessons become skills. On the Learning page, a proven lesson can be turned into a skill with one click.

Memory

  • Clean-up while you're away. Once a day, when the PC has been quiet for ten minutes, memory merges facts saved twice, retires ones nobody has used for 90 days (never pinned ones), and flags pairs that may disagree, like "Lives in Leeds" and "Lives in York".

Connections

  • MCP's new spec. EchoSpeak now talks to MCP servers on the July 2026 spec as well as older ones.
Setup and compatibility
Same as 11.4.1. No data migration: existing MCP servers keep working, and memory clean-up starts counting from today, so no old facts are retired on the first run.
