What changed

Highlights

  • One agent loop for everything.
  • Agents and group chats. Echo, Jarvis (research) and Glados (building) can work alone, hand tasks to each other, answer side by side in a group, or hold a short discussion that ends with one conclusion.
  • Voice that works out of the box.
  • Search past chats. A search box in the sidebar finds any message you or an agent ever wrote, and agents can search old chats too.
  • Sandbox by default. If Docker is running, commands run in a container.
  • Updates in one click. Settings › About shows "Update to x.y.z" when a new release is out.

Agents and group chats

  • Group chats finish what they start.
  • Every agent turn is its own message, in order.
  • Handoffs are capped at 6 per message, an agent can't bounce a task straight back, and the teammate sees your original message.
  • @all or several @mentions answer in parallel when they share a model, then the room's lead posts a short summary.
  • Discussion mode (group settings › How the group answers): agents take turns, up to 4, 6 or 8 messages.
  • Agents have faces that match the website: white Echo, dark teammates, blinking now and then.

Long tasks

  • Honest stop at the step limit.
  • Summarize instead of trimming.

Coding and terminal

  • Native coding tools: paged file reading, exact-text edits, file search and find, background processes.
  • Terminal: Auto (the new default) uses the Docker sandbox when Docker is running, and this PC otherwise.
  • One projects folder in every mode: new projects go to <data folder>\projects.

Channels

  • Discord, Telegram, Twitch and Twitter run on the lean loop.
  • Telegram treats people as the owner only when an allow-list is set.

App

  • Faster, calmer start-up: the backend ships as one folder with no console window, a splash shows instantly, and the boot screen shows real progress ("Step X of Y") with Echo's face spinning.
  • A live status pill above the composer names the agent and what it's doing, with Stop (Esc).
  • New Settings: agents, permissions, terminal, voice, web search, memory, automations, channels.
  • Settings › Advanced holds the less common options, memory and document management, connections and skills, and the companion editor.
  • Safer with untrusted content. After an agent reads a web page, email or channel message, it must ask you before it sends anything, saves a memory, or runs commands online, and it never sends your API keys anywhere.
  • Resizable, collapsible Chats and Projects sections in the sidebar.
  • Polish: one motion curve, focus rings everywhere, better contrast (WCAG AA), reduced-motion support.

Under the hood

  • The state store moved from JSON files to SQLite (phase3/state.db) with a full-text index of every message.
  • The legacy pipeline was removed: about 12,700 lines of core.py and 15 modules.
  • index.tsx was split into modules (12.5k → 9k lines).
  • An evaluation script runs 20 real prompts against a live model (apps/backend/scripts/evalgemma.py).
Setup and compatibility
Windows 10 or 11 (64-bit). For a local model: LM Studio or Ollama (Gemma 4 E4B recommended). Docker Desktop is optional; it enables the sandbox.
