What changed

  • Removed the retired specialist pipeline, execution graph, TaskRun UI and routes, router, mode controller, Go TUI and terminal onboarding wizard.
  • Reduced api/server.py to app setup and middleware; area routers now live in api/routes/.
  • Split the chat timeline, composer input and composer controls from the Dashboard, alongside the provider, voice and history modules.
  • Added project- and Session-scoped uploaded-document search.
  • Tightened terminal authorization after outside content, image loading, approval argument display, child-process key handling and structured tool-output redaction.
  • Updated the web test dependency to a patched version and declared the Node types needed for a clean TypeScript check.
Setup and compatibility
Existing memories and uploaded documents remain in their data folders. If the embedding model changes size, their disposable search index is rebuilt from canonical records and document text. Legacy uploaded documents that lack canonical text may require re-uploading. The installer does not include the optional ONNX model; install it from Settings after updating if you want local semantic search.
