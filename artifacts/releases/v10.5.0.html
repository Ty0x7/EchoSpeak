Expandable three-item lists, grouped provider choices and meaningful empty states reduce clutter. Settings move beside the features they control without dropping saved values.

What changed

Lists

  • Group chats, Projects, Artifacts, Routines and Creations open on their first three items. … Show more reveals the rest and Show less folds them again; nothing is removed or hidden for good.
  • The open group chat or project is never folded away: if it's further down, the list opens already expanded.
  • Creations in progress were capped at 12 and the rest weren't shown at all.

Choosing a model

  • The chat's provider list is grouped into On this PC and Cloud.
  • Switching provider brings back the model saved for it, even before an API key is added or when its catalog can't be reached.
  • The model box says what's happening instead of showing an empty list: "Loading models…", "Add an API key in Settings" or "No models found".
  • llama.cpp is no longer offered in the chat picker, because chats can't run through it.
  • Settings › Models (cloud):
  • One Model choice, which shows whether your API key is saved.
  • Use a custom model ID… opens the exact-ID field only when you need it.
  • Provider names match everywhere: OpenAI, Google Gemini, Claude and Grok.
  • Fixed a bad context-length choice ("63k", 64358 tokens) in Settings › Models.

Settings

  • LM Studio only
  • Memory search
  • Apps agents may open
  • Webhooks
  • Agent-to-agent (A2A)
  • Folders
  • Voice: speech-to-text engine, read-aloud voice and cloud voice, beside the Whisper setup.
  • Channels:
  • Discord access lists and changelog posts join Discord.
  • Mail ports and TLS join Email.
  • Twitter / X and WhatsApp get their own groups.
  • Web search: search timeout, plus the sports odds key under Live data.
  • Automations: the heartbeat's prompt sits under the heartbeat switch.
  • Memory & documents: document search settings sit beside the document list.
  • Memory search: choices are named for what they are: the private search model on this PC, a local model server, or OpenAI.
  • Search: Settings search now finds options by name, for example "twitter", "heartbeat", "whisper" or "api key".
  • Text corrections: the wake-word and Gemini Live notes now match the 10.4.2 composer, and the name field no longer shows a personal placeholder.
  • Routines: if Run or the on/off switch fails, the error now shows in the list instead of only inside the editor.
Setup and compatibility
Same as 10.4.3. No new settings; no data migration. Validation: frontend type checks and unit tests; focused backend tests for provider model lists (including the saved model), cloud catalogs, local provider setup and settings; a browser walkthrough against a fresh local backend for the new lists, the provider picker (grouping, empty states, saved-model restore), Settings › Models and every moved setting, including saving and reading back moved keys. The signed Windows installer, real provider accounts and microphones still need release-machine testing.
