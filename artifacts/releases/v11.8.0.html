A stronger native harness

Native computer-tool support, MCP OAuth/Apps/Tasks, quarantined reading, timing traces, retained tool output and signed remote-agent access extend the existing harness. This work was integrated into 11.9.0 rather than separately installed.

What changed

What's new

  • Hear any reply in an ElevenLabs voice.
  • Screenshots Echo can see, and computer control (from 11.7.1).
  • Claude's own computer tool. With a Claude 5 model and Desktop control, Echo uses the computer tool Claude was trained on: 17 actions, including zoom.
  • Desktop control you can turn on in one place.
  • Longer holds for games. Holds and waits can last 5 seconds (a batch 10); triple-click and sideways scroll are new.
  • Sign in to hosted MCP servers.
  • MCP Apps. A tool that ships its own view (charts, forms, viewers) now shows it in the chat, in a sandboxed frame that can reach only what its server declared, and nothing in Private or Offline mode.
  • Long MCP tasks. Renders and exports that take minutes show their progress, and Stop cancels them on the server.
  • A separate reader for outside content.
  • Timing. Activity › Timing shows where a reply's time went: thinking, each tool, waiting for you.
  • Long results kept whole. A tool result too long for the context is saved, and Echo reads the part it needs by searching or by position, instead of losing the middle.
  • Ask other agents. Add another AI agent (such as a friend's EchoSpeak) in Settings › Advanced › Connections & skills after confirming the fingerprint of the key that signs its card.
  • The Echo bench. scripts/echobench.py runs ten real tasks through the app and records pass or fail per model and version.

Under the hood

  • LangChain is gone. Tools, memory search and document search run on EchoSpeak's own code: the same tool schemas, the same search results, and indexes that never load with pickle.
  • One approval system: the unused 9.x approval routes and card are removed.
  • One set of screen tools: the shadowed legacy screenshot and vision tools are removed; OCR stays for models that can't see images.
  • Inbound A2A now works from other machines: it no longer sits behind the app's API key (it always required its own A2A key).
Setup and compatibility
The first start after updating converts memory and document search indexes to the new format, once, without re-embedding anything. Removed: the Cloud voice: OpenAI audio setting, which never produced speech. Same as 11.7.0. Claude's own computer tool needs a Claude 5 model; ElevenLabs needs your API key; computer control needs Windows.
Verification recorded at the time
Backend tests (972), frontend checks and tests (137) and desktop contract tests (16) pass. The new parts are tested against simulated servers, models and input: two EchoSpeaks pinning and asking each other, a full OAuth sign-in including a refused reply from the wrong issuer, Claude-format computer batches stopping at a failure, ElevenLabs requests and errors, and LangChain-format indexes opening through the real memory and document stores. Real providers, MCP servers, games and desktops vary; report anything that behaves differently on yours.
