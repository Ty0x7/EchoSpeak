Conceptual update flow.

What changed

Chat

  • One input card. The thinking, dictation, Voice and ··· buttons sit inside the input box, under what you type.
  • A clearer context meter. A small ring shows how full the conversation is.
  • Stays at the newest message. Sending a message, resending after an error, or retrying always brings the chat to the bottom.
  • Time with the actions. Each message's time, and the token count for yours, sit on the same line as copy, edit and retry, or copy, read aloud and the thumbs.
  • Research & activity stays out of the way.
  • Full screen works. The research and activity panel fills the window again, with its close button showing.

Sidebar and window

  • The left sidebar is a little wider.
  • More and Less line up with the pages above them.
  • When the sidebar is collapsed, the + button is the same size as the agent faces.
  • The desktop title bar has no line under it.

Setup

  • Setup is its own clean window, with no title bar, status or extra buttons.
  • A progress bar shows where you are.
  • Each step has a short headline that says what it's for, and optional steps have Skip for now.

Settings

  • Agents show their faces correctly again.
  • Advanced › Memory & documents:
  • An overview of how much is remembered, with a colour bar by kind.
  • Filter chips for each kind.
  • One tidy row per memory: pin it with the star, change its kind, or delete it.
  • Advanced › Connections & skills: summary tiles show what's connected and ready, and each item has a coloured status tile.
  • Advanced › Companion matches the rest of Settings, and its preview shows Echo's new glow and every state, including errors.

Git and GitHub

  • They see the current branch and what has changed before they start.
  • They work on a branch, stage specific files and write clear commit messages.
  • They push, open or merge pull requests and create releases only when you ask.
  • They use the GitHub CLI to check pull requests and failing CI.
  • They never force-push or throw away changes they didn't make.
  • Rebasing, discarding changes, merging or closing pull requests, deleting repos and creating releases now ask for your approval first.
Setup and compatibility
Same as 11.2.0. No data migration. To use GitHub features, install the GitHub CLI and run gh auth login once.
