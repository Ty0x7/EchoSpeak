# EchoSpeak development

Follow the [EchoSpeak Evidence-Driven Engineering Cycle](docs/engineering-prompt.md).
Use the loops relevant to the task. Begin substantial work from the latest
verified state and report the checks that establish the outcome.

## Project documentation

Use the project `project-documentation` skill when meaningful completed work
benefits from technical Markdown and visual HTML. Its canonical instructions
are in `.agents/skills/project-documentation/SKILL.md`. Reuse relevant existing
docs and preserve user files. Small changes do not require new reports.
