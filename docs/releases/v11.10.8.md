# EchoSpeak 11.10.8 — Reliability hotfix

> **Status:** a source hotfix prepared on `claude/reliability-11108` from the [27 Oct system review](../research/system-review-2026-10-27.md). The owner builds, installs, tests and publishes it. Replacing 11.10.7's published binaries is out of scope. Not published on its own: it ships as part of [11.10.9](v11.10.9.md).

Echo reports what actually happened more truthfully and no longer locks itself out after a refused action. Ordinary chat is lighter on local models, webhooks deliver their data, and Echo can fix a GitHub issue and open a pull request for your review.

## Truthful outcomes and work coordination

- A tool that refused its arguments before doing anything (a bad coordinate, a missing file, a denied path) is recorded as a plain failure, not an "unknown effect" that blocks later work (R1). Lost receipts, timeouts and mid-batch cancels still count as unknown.
- A computer action cancelled mid-batch reports how many steps started, so a pressed key or click is never mistaken for nothing happening.
- An action that would collide with another task's held resource returns a readable "Not run: …" tool result. Before, it crashed the whole turn (R2). The message names the resource, the holding task, and where to resolve it in Activity › Agent work.
- A dev server started by a task no longer blocks that task's own next edit. It still holds the project against other tasks until its exit is seen (R3). A task can complete while its process keeps running.
- Legacy tool outputs that report failure are recorded as failures (R5). This covers ~40 known shapes, including `❌ Failed…` from every skill, `[TAG] ok=false`, "Path not found" and "Playwright is not available".
- Signed webhooks pass their body to the routine as clearly marked outside content (R17).
- Answered approval questions no longer show as still pending. Recovering an approval after a restart checks whether a live turn still holds it.

## Ordinary chat

- A question no longer creates a durable work record. Work starts at the first real state-changing tool call (R4), and interactive replies don't write a redundant outbox row.
- Group "reply" rooms skip the extra completion-check model call for a plain question that was answered without tools, tasks or repetition (R8). Requests still get checked.
- On local models, ordinary chat lists the everyday tools up front, and the rest load through `find_tools` while staying callable by name (R12). Measured on the default setup: 32 → 19 tool schemas, about 6.8k → 5.0k prompt tokens. Cloud models are unchanged.
- **Settings › General › Your name** now reaches the agent. **Settings › Memory › Remember conversations** now controls whether agents search past chats (R7).
- Finished work history older than 30 days is pruned from the coordination ledger hourly (R10). Unknown, waiting, running or unsettled records stay until you resolve them.

## GitHub issue → fix → pull request

- New `github_create_pull_request` tool opens a pull request from a pushed branch, as a draft by default. It asks you every time, in every approval mode, and can't be "always allowed". It never merges.
- New bundled Agent Skill **github-issue-to-pr**: read the issue, branch, fix, test, commit, push, open the PR, report. It refuses to merge, force-push, push to the default branch or touch your uncommitted work. Import and approve it in Settings like any skill.
- `gh` commands that write (`gh pr create/merge/edit`, `gh issue comment`, `gh api`, release/repo changes) now ask in the terminal too.
- Fixes an approval gap: GitHub comments, Calendar create/delete and Notion append ran without asking in the default mode, because the approval list used names that matched no registered tool.
- The installer now bundles the Calendar, GitHub and Notion libraries and checks them at build time (R6).

## Windows file safety

- Every JSON and settings writer retries briefly when Windows reports a sharing violation (an indexer, scanner or reader holding the file). Before, those writes failed outright, including Echo Code's `session.json` and the MCP trust pins.
- Chat turns created in the same clock tick keep their order, so branching a chat cuts at the right message.

## Release metadata

- 11.10.7's in-app update text said no installer had been built. Its `latest.json` notes and GitHub release text were corrected on 27 Oct 2026. Signatures, links and binaries are unchanged. The release script now refuses notes that read as unreleased.

## Known limits

- Live-model behavior, an installed-app run, and the owner checklist in the system review are pending owner acceptance.
- After a backend restart, a task's still-running background process is marked unknown, which is conservative. Reconcile it in Activity.
- The desktop remains one shared resource for all tasks.
- A budget or pause check can still end a turn.
- Failed deliveries are retried on every scheduler tick.

```powershell

```

Install and test it. After reviewing and merging the PR, publish the exact tested build with `scripts/release-windows.ps1 -SkipBuild -Publish`.
