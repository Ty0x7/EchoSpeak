# EchoSpeak 11.9.3

## Project Work

* Work shows HTML reports and native HTML artifacts only. Markdown stays in Files and paired Technical notes; earlier imported reports remain under Files. Other native artifacts and creations remain in their existing libraries.
* Widgets and List controls sit beside Find project work. The chosen view persists on this device, with keyboard focus and pressed-state labels.
* Each report refreshes from its own file and local-media revision. Unrelated changes no longer clear its thumbnail or reload its open HTML. Replacement images decode before being displayed. Actual changes to an open HTML document reload its sandbox and may reset that document's scroll.
* Images use the full preview width without stretching or cropping. HTML previews scale to the actual card width and height.
* Removes Activity from project sections and stops its repeated execution queries. Existing chat activity, timing and stored execution history remain available.

## Project identity

* A pencil beside each project's New chat button opens Edit project. Rename its display label, choose a local logo, or restore the folder icon.
* Names and logos persist in the existing project store. This does not rename or move the attached folder. Existing metadata, trust, research and conversations are preserved.
* PNG, JPEG and WebP logos are limited to 2 MB and 16 megapixels, decoded and re-encoded as static thumbnails up to 256 pixels. Remote URLs, SVG, paths, invalid images and oversized uploads are rejected. A failed update leaves the saved project unchanged.

## Documentation and continuity

* Canonical Codex/Echo instructions and the Claude adapter explicitly follow the current attached project's colors, typography, spacing and assets. Hosting a preview in EchoSpeak does not impose EchoSpeak's theme on another project.
* The compact optional HTML starter is structural guidance, not a mandatory visual theme. Existing imported custom skill files and their approval state are not silently replaced; changed imports require owner review.
* Updates the current workspace guide and visual report, reviews existing HTML reports, and adds this release to the visual atlas. Older release reports describe historical behavior, not the current UI.
* Carries forward the existing 11.8/11.9 harness and optional 11.9.2 voice work. The previously reserved A2A architecture expansion is future work, not a feature claimed by 11.9.3.
* Aligns backend, web, desktop, Cargo and Tauri release metadata to 11.9.3.

## Verification and limits

Focused offline backend checks passed 72 tests, with one Windows symlink test skipped. The frontend suite passed 153 tests. Type checking, the production web build and both skill validators passed. Checks use disposable project state and block real providers.

Isolated actual React components passed wide/square/phone layout checks at 1280, 960 and 390 pixels, HTML-only filtering, saved list mode, image/HTML framing, unchanged thumbnail and open-file scroll retention on unrelated refreshes, name/logo editing and removal, and modal Escape behavior. Actual repository discovery opened the current report and its Technical notes with a 55-pixel project header and GET-only workspace requests. No browser exceptions or external requests were observed.

All 31 version reports and the atlas passed 64 responsive renders, with valid local links/media, correct file pairing, no overflow and no external requests. Older version-note hashes were unchanged.

No Windows installer was built or published during development. Installed-app updates, user workflows and independent agents remain owner testing. No live model calls, paid APIs or global agent settings were used or changed.
