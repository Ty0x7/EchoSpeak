# EchoSpeak 11.16.0

EchoSpeak 11.16.0 brings conversation scrollback and one-step session navigation to the terminal, adds cross-monitor Companion placement, and coordinates model residency across local runtimes.

> Release preparation started on 28 November 2026 from main revision `39c3ea3`. The latest published Windows installer at preparation time is [11.12.0](https://github.com/Ty0x7/EchoSpeak/releases/tag/v11.12.0).

## What changed

- **Companion follows session activity.** See what supported Claude Code, Codex and Echo sessions are working on. Companion can summarize a project and speak a check-in when meaningful new activity arrives. [Companion architecture](../research/echo-companion-architecture.md)
- **Local model context is measurable.** EchoSpeak can use a dedicated Bonsai llama-server endpoint alongside Ollama and LM Studio. The llama-server integration reads the context allocated to a running slot so that multiple slots do not inflate the reported working window. See the accepted [context detection](https://github.com/Ty0x7/EchoSpeak/pull/241) and [Bonsai integration](https://github.com/Ty0x7/EchoSpeak/pull/243).
- **Project work is easier to inspect.** Environment discovery and chat-initiated MCP connections help locate tools and connect supported services. Desktop and terminal share project sessions, and interrupted sessions can be removed without losing unrelated conversations. [Environment discovery](https://github.com/Ty0x7/EchoSpeak/pull/206) · [Session recovery](https://github.com/Ty0x7/EchoSpeak/pull/232)

## Everyday use

- In the terminal, wheel over the conversation or use Page Up and Page Down. Ctrl+End returns to live output. A single Left arrow from an empty composer opens the full session manager.
- Use `/companion show|hide|on|off|status` in the terminal, or Echo Companion in desktop Settings. Auto-hide keeps the Companion available for new activity. Manual hide stays in effect until you show it.
- The terminal model picker can switch between local runtimes. Ollama context profiles are listed under context settings when the base model is still installed.
- EchoSpeak holds local inference admission through generation so another EchoSpeak session cannot swap out its active model. Companion uses its templates when optional wording would require loading another model.

## Check your installation

Open **Settings → About** for the desktop build. Run `echospeak --version` for the installed terminal client and `echospeak backend status` for the backend it found. These commands can report different versions when components were installed separately.

The public downloads page follows [GitHub Releases](https://github.com/Ty0x7/EchoSpeak/releases/latest). Windows publication requires installer assets built from this revision, an updater signature made with the existing key, and a Windows install and upgrade check. For the Windows release workbook, follow [the desktop build instructions](../../apps/desktop/README.md).
