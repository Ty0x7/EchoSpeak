# EchoSpeak 11.11.1 — A better Chat: diagrams that draw, sharper answers

> **Status:** source release on `claude/chat-harness`, built on 11.11.0. The owner builds, installs, tests and publishes it.

Chat now draws diagrams and math reliably, while a reply streams, after it finishes and after a reload, and answers more like a capable general assistant: direct, well-judged, researched when it matters, and limited to what a chat should do.

## Diagrams, math and rich answers

- **Mermaid diagrams draw.** Before, most failures were small syntax slips models often make, such as a label with brackets or a colon. Mermaid rejected them and Chat showed the source code. Chat now fixes those slips and draws the diagram, marked "syntax fixed". Source always shows what the model wrote.
- **Diagrams appear as soon as they're written,** while the rest of the reply is still streaming. They no longer wait for the end.
- **Every reply renders the same way.** Some replies, such as one shown from its final text after a queued follow-up, used a plainer renderer that showed diagrams, math and charts as code.
- **Math in `\( … \)` and `\[ … \]` renders.** That's how ChatGPT-style models write it. A price like $5 stays text.
- **Light theme diagrams** use light colours and redraw when you switch theme.
- **A diagram that truly can't be drawn** says why: Mermaid's message, the line with a caret pointing at the problem, and the source with a Copy button.
- **Diagrams stay readable on a narrow window.** A wide one scrolls inside its card instead of shrinking to unreadable text.

## Chat answers like a chat assistant

- **Chat has its own instructions,** instead of Echo's agent rules:
  - Answer first, then the why, then an example.
  - Match the depth to the question.
  - Give a recommendation, and say what's uncertain.
  - Assume sensibly instead of asking, and don't flatter.
  - Format cleanly.
- **Smarter about tools.**
  - Chat answers what it knows without searching.
  - It searches for anything current or niche.
  - For real research it runs several searches, reads the pages and cites the ones it read.
  - It no longer carries instructions that pushed it to "keep going" like an autonomous agent.
- **Your model stays your model.** Smart model choice never swaps the model you picked in Chat.

## What Chat can do

- **Chat can:** search and read the web, show live cards, read files you point at and images you share, remember, calculate, make artifacts, images and video, set reminders, and use your connected apps (which ask first).
- **One optional action:** opening an app by name. It asks first, takes no arguments and never opens a command shell. It still needs the Open apps permission.
- **Chat can't:** run commands, change files, use the mouse and keyboard, capture the screen, drive a browser or send email.
  - Those stay in Agents and Code, enforced in the app itself, even with every permission switched on.
  - Chat tells you in a sentence and suggests sending the task to an agent.

## Memory in Chat

- Chat uses what you've told EchoSpeak about yourself, but not the notes your specialist agents keep for their own work.
- When you refer back to an earlier conversation, Chat looks through your Chat conversations, not your agents' or coding sessions.

## Verification

- **Scripted:** targeted tests for this work:
  - Chat's tools, with every permission on
  - the run-time refusal of agent tools, including "bash"
  - Chat's prompt and memory scope
  - the diagram repair rules and math handling
- **A new real-browser check** (`apps/desktop/scripts/check-chat-render-browser.cjs`) runs the production build with real Mermaid and KaTeX. It checks rendering while streaming, after streaming and after a reload, in dark and light themes and at desktop and phone widths.
- **Needs your test with a real model in Chat:**
  - Ask for a diagram, a formula and a comparison table.
  - Ask a quick question, which should be answered without searching.
  - Ask a research question, which should use several sources, with links.
