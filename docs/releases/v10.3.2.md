# EchoSpeak 10.3.2

Chat navigation now preserves live agent work, data tables keep their own layout, and the Creations library matches the other sidebar pages.

## Changes

- Each chat owns its live transcript and event queue. Switching chats or opening another sidebar page keeps incoming text, thinking, tools and approval events attached to the original chat.
- Return to a running chat to see its latest progress. Replies completed while hidden are committed to that chat's cached timeline. Another chat's completion cannot clear the active chat's live turn.
- Explicit Stop still targets the selected chat. Superseding or deleting a turn clears only that chat's stream state. Closing the application is not covered by in-app background navigation and still follows the existing cancellation behavior.
- Markdown data tables use a real full-width table, properly padded cells and readable minimum column widths. Narrow layouts scroll inside the table rather than breaking short labels in half. Sorting and both copy actions remain available. Other widget types retain their existing styles.
- Creations uses the shared sidebar page cards, empty/loading states, typography and controls. Searching, media filters, archive/restore, renaming, downloads and opening the original chat remain available.

## Validation

TypeScript checks and 14 focused frontend tests passed. A browser check with controlled model streams covered two simultaneous chats, tokens received while hidden, switching back during a run, sidebar-page navigation, hidden completion, and no cancellation or cross-chat output. The two reported table examples were rendered and inspected at wide and narrow widths, along with the Creations empty state. The production frontend build passed.

Live model/account testing and Windows installer signing remain part of the user testing handoff. This update does not introduce a new research-notebook screen.
