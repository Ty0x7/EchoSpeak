# EchoSpeak 11.15.0 — Everything since 11.14 in one release

> **Status:** Installed and verified on Linux from `main` at `e3f8c4c`. Open EchoSpeak from the applications menu or run `echospeak` in a terminal.
> Not published as a GitHub release; no Windows installer was built.

11.15.0 gathers the work of 16–20 November that had been spread over a dozen local branches, worktrees and an
outdated running backend. The integration ledger lists every branch and why it was taken or left
([integration-11.15.md](../research/integration-11.15.md)).

## What changes for you

| Area | Before | Now |
|---|---|---|
| One assistant | (11.14.1, unmerged) | A trusted project adds file and terminal tools to Echo; one list of conversations; a session manager behind ← |
| Reading files outside a project | Refused outright | The normal approval card: allow once, for this chat, or always (revocable, read-only). Credentials are never readable |
| Remembering | "I've noted that" with nothing saved; old values kept after a change | A claimed or requested save that didn't happen gets one step to happen; a changed fact replaces the old one by key (memory ×4: 51/56 → 60/60) |
| Past conversations | `chat_search` needed every word of a description | Ranked partial matches, newest first, never the current turn |
| Long tasks | Stopped at the step limit and waited for "Continue" | Carries on while it is still making progress (up to 5 stretches), with the work budget extended alongside |
| "why stopped? and continue" | Became the objective; the next turn couldn't see the last turn's files | Continues the unfinished objective, is told why the last turn stopped, and sees a record of what each turn changed |
| Context at 16K | Compaction summaries piled up; older file reads were cut to their first characters | One summary, rewritten each time; trimmed reads keep their outline (classes and functions with line numbers) and the list of files read |
| Connected apps (MCP) | Tools of a named app were hidden behind find_tools; app work ran out of steps | The app's tools stay listed when you name it; app work extends the step budget; `find_tools` matches app names (X1/XH1 ×8: 3/8 → 8/8) |
| Delegation | Primary agents in a project couldn't hand work to each other | Project members, spawned helpers and "tell Jarvis …" messages (`message_agent`) |
| Honesty | A refused write could be reported as done; a test's expected value could be hard-coded | W1 and the D7/H7 ledger fixes: both ×4 confirmed |
| Opening what Echo made | Launchers that hand off to the browser looked like failures (5 relaunches, 6 approvals) | Counted as opened; in the sandbox with no desktop, Echo is told to open it once on this PC |
| Python tests | `python3 -m pytest` failed in the sandbox and `pip install` went to another Python | The error says which Python and the route that works (`.venv`, bare `pytest`) |
| Terminal | — | Square animated Echo, clean start, /settings, /permissions, /tools; failed steps say "Couldn't …"; errors without raw JSON; "← sessions" kept down to 64 columns |
| Tests | 22 long-standing backend failures | All traced; none was a product bug; the backend suite is green |
