# EchoSpeak 10.3.0

Create images and videos from chat, keep them in Creations, research with retained sources, and configure your first installation through a guided setup.

- **Creations:** a library below Routines with image/video previews, downloads, names, archive/restore, and links back to the originating chat.
- **Generation:** Gemini image generation, Google Veo video, MiniMax Hailuo video, and local ComfyUI workflows. Cloud submissions require approval. Jobs and completed assets use EchoSpeak's existing durable stores.
- **Optional local setup:** hardware detection and verified downloads for an isolated Windows NVIDIA ComfyUI runtime, Stable Diffusion 1.5 images, and Wan 2.1 videos. Other hardware can connect an existing loopback ComfyUI installation. Models are not bundled into the installer.
- **Research:** Tavily joins DuckDuckGo, Brave and SearXNG; page reading adds main-content extraction, links and PDFs. A chat-scoped notebook retains inspected sources, passages and working notes for seven days, separately from personal memory.
- **First-run setup:** a resumable checklist reuses model, search, sandbox, voice and creation settings. Optional steps can be skipped. Existing installations can open it from Settings → General → Setup.

## Validation and testing handoff

Frontend type checking, 108 existing frontend tests, and the production web build passed. The backend regression run passed 430 tests, skipped 37 and reported five failures: four were isolated test-environment Windows import configuration, and one asserted the previous absence of Tavily. After correcting those, the targeted run passed all 35 tests, including 15 new generation/research tests. A complete backend rerun was not performed at the user's request.

Live paid provider calls, full local-model installation/GPU generation, Windows installer signing and desktop interaction are left for user testing. Provider model access depends on the account; local generation speed and compatibility depend on the GPU. Stopping a job stops waiting and saving its result, but cannot guarantee cancellation of provider processing or billing. Interrupted jobs are reported after restart rather than automatically resubmitted.
