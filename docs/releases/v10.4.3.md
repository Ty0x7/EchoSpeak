# EchoSpeak 10.4.3

EchoSpeak 10.4.3 updates Windows installer branding, replaces startup shortcut-repair scripts with native installer maintenance, and simplifies the public guides. All 10.4.2 chat and voice improvements carry forward.

- The installer and uninstaller use the current Echo icon. Welcome and setup pages also use Echo branding.
- The app no longer launches PowerShell to rewrite shortcuts on every startup. Installation repairs standard shortcuts with recognized installation targets; independent older copies may need their pins replaced manually.
- Approved Windows terminal commands respect the host's PowerShell execution policy.
- Public release publishing verifies Windows publisher signatures on the installer, desktop app and backend separately from updater signatures. Certificate signing supports both user and machine certificate stores.
- Public guides focus on setup and everyday use. Maintainer build, signing and publishing recipes were removed; outdated Live mic instructions were corrected.
- Installation guidance no longer tells users to bypass Windows warnings.

Windows publisher signing requires a valid publisher certificate or signing service. Code changes and signing do not guarantee immediate SmartScreen reputation or removal of a Defender detection. A fresh installer and real Windows installation still need verification before distribution.
