# EchoSpeak 11.7.0

Private Mode you can check, and models chosen by what actually worked on your PC.

## What's new

- **Private and Offline modes.** Settings › Privacy has three modes:
  - **Standard:** everything works as you set it up, and Echo shows what talks to the internet.
  - **Private:** your messages, files, memories and searches never go to a service outside your machines. Local models (LM Studio, Ollama) and your own SearXNG keep working.
  - **Offline:** only this PC and your own network.
- **Enforced, not just a setting.** Each part of EchoSpeak asks before it connects, and a backstop refuses any internet connection that nothing approved. Blocked features say why in plain words. For example, web search in Private mode explains that your own SearXNG would work.
- **A privacy check.** It probes your setup: does your local model answer, does your SearXNG return results, which saved cloud keys go unused, and what would still leave your machines. It also lists what a mode can't control, such as programs EchoSpeak starts and other apps on your PC.
- **What talks to the internet.** Each part of EchoSpeak, what it sends, and the connections since startup (host names only, kept in memory, never saved). Any part can be switched on or off, and you can add hosts you trust, like your own search server on a VPS.
- **Smart model choice (optional, off by default).** Settings › Models. Echo learns which of your models does each kind of task best, from tasks finished with proof on your PC:
  - **Suggest:** an agent notes when another model you listed has done clearly better.
  - **Choose for me:** the agents you pick use the model with the best record. Only models you listed are used, paid cloud models only if you allow them, within a daily token cap.

  Every pick says why under the reply. Outages and missing keys never count against a model.
- **Smarter connection search.** Echo can find connected-app tools and setup guides by meaning, using the memory-search model it already has. It also remembers earlier setups: already connected, dismissed, or still waiting for you.
- **README:** who Echo is for, and how to run it fully private.

## Requirements

Same as 11.6.0. Private mode with web search needs your own SearXNG with its JSON format enabled. Smart model choice needs learning on (the default) and some history before it compares models.

## Validation

- Backend tests, including new suites for privacy (with a real backstop test in a separate process), model choice and search by meaning.
- Frontend type checks and unit tests.
- Desktop contract tests.
