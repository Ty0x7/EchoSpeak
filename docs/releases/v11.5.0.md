# EchoSpeak 11.5.0

Agents that recover instead of giving up, a way to stop everything at once, skills in the open format other agents use, and a tidier memory. Everything from 11.4.1 carries forward.

## What's new

### When something goes wrong

- **Agents ask instead of giving up.** When an agent is stuck, or a choice is yours, it shows a short question with a few choices (plus "Something else") and carries on with your answer.
- **Errors say what to do next.** If web search fails, the agent hears why and what to try: another route first, then asking you. It no longer stops at "sorry".
- **A system check.** Settings › System check shows whether web search, page reading, the model, speech to text and memory search are working, and how to fix what isn't. If something important is broken, a notice above the chat says so when the app starts.
- **A check before "done".** When an agent changes code, it runs the code or its tests before saying it's finished, or tells you plainly that it couldn't check.

### Staying in charge

- **Stop everything.** One button at the bottom of the sidebar (click it twice) cancels every running agent and pauses routines, Discord and Telegram replies, and outside agents until you press Resume. Your own chats keep working. The pause stays on after a restart.
- **Limits on outgoing messages.** Agents can send at most 5 messages a minute and 30 an hour on each channel (email, Discord, Telegram and so on), so a confused agent can't spam your contacts.
- **MCP servers wait for your OK.** A new or edited MCP server doesn't start until you approve it in Settings › Advanced › Connections & skills, and if an approved server changes its tools, they stay off until you approve again. Servers you already had are trusted once on upgrade.

### Skills

- **Agent Skills.** Settings › Skills imports skills in the open SKILL.md format: from a folder, or by pasting one. Agents see only each skill's name and description, and read the rest when a task needs it. Nothing is used until you approve it, and a skill that changes needs approving again.
- **Lessons become skills.** On the Learning page, a proven lesson can be turned into a skill with one click.

### Memory

- **Clean-up while you're away.** Once a day, when the PC has been quiet for ten minutes, memory merges facts saved twice, retires ones nobody has used for 90 days (never pinned ones), and flags pairs that may disagree, like "Lives in Leeds" and "Lives in York". You decide which to keep in Settings › Advanced › Memory. Nothing is deleted.

### Connections

- **MCP's new spec.** EchoSpeak now talks to MCP servers on the July 2026 spec as well as older ones.

## Requirements

Same as 11.4.1. No data migration: existing MCP servers keep working, and memory clean-up starts counting from today, so no old facts are retired on the first run.

## Validation

- Backend tests, including new ones for questions, search errors, the system check, skills, Stop everything, outgoing limits, MCP approval, memory clean-up, the check before "done", and the first replay case from a real chat.
- Frontend type checks, unit tests and the production build. 16 desktop contract tests.
- MCP tested with both SDK 1.x and 2.3.
- Checked in the browser: the search notice and System check, approving a skill, and Stop everything with Resume.
