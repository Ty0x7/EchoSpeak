# EchoSpeak 10.1.0

Group chats now finish the work instead of just talking about it, agents only say they saved something when it really saved, the terminal stops getting stuck, and the chat no longer pulls you away from what you're reading.

## What's new

- **Work together.** The old "Discussion" group mode is now **Work together**. The team shares a quick plan, the lead hands out tasks ("Glados → write the script · Echo → run the tests"), each agent does its part with real tools, and EchoSpeak checks the result against what you asked. If something is missing or a test fails, it goes back to the right agent and continues. When it's verified, Echo sums up what was done and asks if you need anything else. Groups can now run 15, 30 or 60 turns (default 30); your existing discussion groups switch over automatically.
- **It stops for a reason, and tells you.** A run ends with **✓ Done** and a summary, or **Stopped:** with the reason (it used its turns, it stopped making progress, it was going in circles).
- **Echo can update its own personality, for real.** Ask "from now on, keep answers short and save that to your soul" and Echo changes its Soul. You see an approval card with the exact change first, the change is saved and read back, and it's still there in new chats. If saving fails, Echo says so.
- **No more made-up "I saved it".** If an agent says it saved, sent or remembered something but didn't actually do it, it is asked to do it or correct itself, and you see a "Not verified" note if it doesn't. Saved memories are checked on disk too.

## Better at the terminal

- Long builds and installs are no longer cut off at the time limit: they keep running in the background and the agent checks on them.
- Dev servers (`npm run dev`, `vite`, `python -m http.server`, …) start in the background in seconds instead of blocking for two minutes.
- Commands never hang waiting for typing. Ones that need a keyboard (vim, `npm init`, a bare `python`) get the non-interactive version suggested instead.
- Errors are clearer ("that program isn't installed", "use ; instead of && in PowerShell"), and files changed by a command can be undone like any other edit.

## Smarter context

- Teammates remember what matters for *their* task and know what the chat has been about.
- Say "like last time" or "what we talked about yesterday" and Echo pulls up the matching past conversation by itself.
- Long tasks get a regular "are you still on track?" reminder, so agents change approach instead of repeating failing steps.
- Agents carry fewer, clearer tools (Glados no longer gets shopping and stock tools).

## Chat scrolling

- At the bottom, the chat follows every new message, including fast group runs.
- Scroll up and it stays exactly where you are while agents keep talking. Scroll back down and it follows again.

## Requirements

Same as 10.0.0. No new settings. Your agents' tool settings are updated once on first start.
