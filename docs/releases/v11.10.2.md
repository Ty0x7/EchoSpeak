# EchoSpeak 11.10.2

Echo can remind you now. Ask "remind me Sunday at 4 about the game", and the reminder appears in that chat and as a Windows notification. If you choose, closing the window keeps EchoSpeak running in the system tray, so reminders still arrive.

## Reminders
* Ask in plain words: "remind me Sunday at 4", "in 20 minutes", "every weekday at 8". Echo says the exact time back.
* Reminders can be one-time or repeating. Ask Echo to list them, or to cancel one.
* A plain reminder posts itself, with no AI call, so it works even when your model isn't running.
* A reminder can also do something at that time ("check the final score"). Anything that needs your approval is skipped and reported.
* Reminders show on the Routines page, where you can cancel them.
* If EchoSpeak was closed at that time, the reminder arrives when you next open it, marked late.

## Notifications
* Reminders show as Windows notifications, even when the window is closed to the tray.
* Discord and Telegram receive them too, if you've set those up.

## Keep running in the tray
* Settings › General › **Keep running in the tray when closed**. It's off by default.
* With it on, closing the window hides EchoSpeak to the tray (Show hidden icons on the taskbar) instead of quitting.
* Click the tray icon to reopen EchoSpeak. Right-click it and choose **Quit EchoSpeak** to quit for real.

## Verification
* Backend and web test suites pass, and the desktop shell compiles with tests for its notification check.
* A real tray icon and real Windows notifications need the installed app; that's owner testing. Windows shows notifications only for installed apps.

## Limits
* Reminders need EchoSpeak running. The tray keeps it running when the window is closed, but not through a restart of Windows, and there's no start-with-Windows yet.
* A reminder can be up to a minute late.
* Clicking a notification doesn't open its chat.
