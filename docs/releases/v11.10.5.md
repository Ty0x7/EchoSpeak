# EchoSpeak 11.10.5

This UI update cleans up Chat, Echo Code and voice mode using the owner's annotated screenshots: a black desktop header, quieter sidebar, compact composer, consistent dark chat surface and one connected-model catalog.

## Header and sidebar

- The titlebar matches the sidebar. Normal desktop windows also start with a black webview background.
- Removes the duplicate EchoSpeak logo/name inside the sidebar. The desktop titlebar retains the app identity.
- Puts a gray Chat/Echo Code switch on a black button beside Search chats and Collapse. Chats now appear above Agents, including in the collapsed rail; saved section sizes remain intact.
- The session breadcrumb and Research & activity control share the first content row, with research on the right.

## Chat and composer

- Empty and populated conversations use the same darker background. The composer has no extra gray surrounding dock.
- The editable area starts at one line, grows for longer messages and shrinks when cleared. Mouse and keyboard focus no longer draw a white rectangle around the inner textarea; keyboard focus remains visible on the composer border.
- Empty-chat content sits higher. Beneath the welcome title, three descriptions type, pause, erase and loop. Accessible descriptive text stays visually hidden. Reduced motion shows one complete phrase.

## Models and coding runtimes

- The shared Chat/Code model popup has one EchoSpeak mark instead of provider initials. It combines Local and API models from catalogs that report reachable connections; disconnected catalogs are excluded.
- An explicitly ready built-in GGUF model remains selectable even though that runtime has no HTTP catalog.
- Search, favorites and keyboard choice remain available. Choosing a row selects its provider and model together; browsing does not switch providers or run inference. Configure providers still opens the existing settings.
- Echo Code's runtime trigger and menu have small, bounded Echo, OpenAI/Codex and Claude marks. Codex, Claude Code and ACP execution remains unavailable; logos do not imply runtime support or account access.

## Voice

- Echo is centered with Listen/Pause and Back to chat in the normal view. Decorative headings, paused captions, level bars and the empty transcript prompt are removed.
- Back to chat restores the transcript. Actual voice errors and pending approvals remain visible rather than being silently hidden.

## Verification and remaining acceptance

See the [verification record](../research/echo-code-verification.json) for current checks and historical baseline evidence. Desktop UI screenshots use the real React desktop components with a mocked native bridge/API and synthetic microphone. They are not installed WebView2, real microphone, live model or provider-entitlement proof.

The updater signing key requires its owner's local password. No 11.10.5 signed installer or publication is claimed by source/UI verification. Run the normal release build from `apps/desktop`, enter the password locally, install/test the resulting version, then publish explicitly:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/release-windows.ps1
# After installing and testing release/v11.10.5/EchoSpeak_11.10.5_x64-setup.exe:
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/release-windows.ps1 -SkipBuild -Publish
```
