# EchoSpeak 11.11.4 — Chat answers once, and stands by it

> **Status:** source release on `claude/chat-reliability`, built on 11.11.3. The owner builds, installs, tests and publishes it.

Chat no longer erases an answer it has started showing and thinks again. Checks on an answer now leave a short note under it instead of a rewrite. Answers cut off by the model's output limit continue where they stopped, and EchoSpeak's own instructions to the model can no longer be mistaken for you.

## One answer, no second thinking

- **The "second thinking" and the rewritten answers were EchoSpeak's own checks.** After an answer streamed in, a citation or claim check could erase it and ask the model to try again. It asked in a way the model read as *you* complaining, so it apologised and started over. Now:
  - An answer that's been written stays.
  - A link to a page that wasn't read, or couldn't back the answer, loses its link (the words stay), and a note under the answer says so.
  - "I've saved it" when nothing was saved gets a "Not verified" note instead of a rewrite.
- **Answers cut off by the output limit continue.** A long answer that hit the model's limit used to stop mid-sentence. It now continues in the same answer, without another thinking phase.
- **When thinking used up the whole limit,** the model answers from where its thinking ended instead of starting over.
- **EchoSpeak's instructions to the model are marked as coming from the app,** in Chat and Agents, so the model never answers them as if you'd said them.

## More trustworthy answers

- **Figures are checked:** money, percentages and other numbers that don't appear in any page or result Chat read are listed under the answer as unverified.
- **Official sources come first for rules:** for questions about laws, taxes, rates, deadlines or time changes, government and regulator sites (such as alberta.ca) rank above blogs and news.
- **"What's new in EchoSpeak?"** reads EchoSpeak's own pull requests and releases, instead of searching and finding other apps with the same name.
- **Chat knows the app it's in:** your actual agents, Chat, Agents and Code.

## Smaller fixes

- **Weather and live data:** Chat's capability list names the actual tools, so a small model no longer tries to load "Live data cards" as if it were a skill.
- **Sports times** say they're in your time zone ("7:00 PM Alberta Daylight Time").
- **Memory:** remembered facts show when they were saved and whether they're about the current project.
- **Mermaid:** a diagram that fails because of a problem inside Mermaid is no longer reported as your syntax error.
- **PDF and Excel:** Chat says it can't make PDF or Excel files. It offers Markdown, printable HTML or a CSV that opens in Excel, instead of silently giving you something else.

## Verification

- **Focused tests run the real loop with a scripted model.** They record every model call and stream event and cover:
  - an unverified link is fixed in place with no second generation and no erased answer
  - an untrue claim is noted, not rewritten
  - an answer cut off by the limit continues with thinking off
  - thinking that used the whole limit is answered from, not restarted
  - the app's notes keep message order
  - figures are checked
  - capability names, official-source ranking, memory dates and sports time zones
- **The existing Chat, Agents, search and memory tests** for the changed parts pass. So do the web tests and the real-browser rendering check.
