# EchoSpeak 11.10.7 — Native agent work foundation

Prepared source release; no installer built, installed or published by this work.

- Durable native work, attempts, progress, bounded specialist/worker grants and safe resume across conversations.
- Recoverable exact approvals and questions, interrupted-effect reconciliation, cooperative resource admission and prior-effect replay protection.
- Owner-reviewed specialist/responsibility proposals, stable scheduled/event occurrences, model-free reminders and tracked result delivery.
- Scoped specialist context/working notes, linked learning evidence and existing reviewed skills.
- Work/review controls in Activity; stable Telegram owner identity; centered Chat/Code transcript columns.
- Includes the earlier model compatibility audit through the stacked branch dependency; external Codex/Claude/ACP harnesses retain their original execution paths.

See [engineering report](../research/multi-agent-review.md), [visual architecture](../../artifacts/research/multi-agent-review.html) and [manual acceptance](../TESTING_GUIDE.md).

From `apps/desktop`, build the installer with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/release-windows.ps1
```

Install and test the new bundle. Only after reviewing and merging the stacked PRs, publish the exact tested build using `scripts/release-windows.ps1 -SkipBuild -Publish`. A PR push or merge does not publish an EXE. Never use `-SkipBuild` to reuse the earlier 11.10.6 binaries.
