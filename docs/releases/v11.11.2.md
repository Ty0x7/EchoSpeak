# EchoSpeak 11.11.2 — Chat answers from evidence

> **Status:** source release on `claude/chat-orchestration`, built on 11.11.1. The owner builds, installs, tests and publishes it.

Chat now keeps track of what it actually searched and read, checks the links in its answer against that, carries the pages it read into follow-up questions, and always finishes with an answer instead of stopping when it runs out of steps.

## Answers grounded in what Chat read

- **Chat keeps a record of each answer's evidence:** the searches it ran, the results it saw, the pages it opened, the files it read.
- **Links are checked before you see the answer.** If Chat researched and its answer links a page that no search or page returned, it's asked once to replace that link with one it actually used or remove it. The same applies if it read pages but cites none of them. Links in a plain-knowledge answer, such as to well-known documentation, are left alone.
- **Follow-ups remember the sources.** Pages Chat read earlier in the conversation stay available, so "what did that article say about…" can be answered and cited without searching again.
- **When disagreeing sources come up,** Chat is told to say so, prefer the primary or newest source and explain why, and stop searching once it has enough.

## Always an answer

- **Chat has a step budget sized to your model:** 10 steps on larger and API models, 6 on small local ones.
- **If research uses it up,** Chat answers from what it found and says what it couldn't confirm. It no longer stops with "I ran out of steps".

## Small models, big models

- **On small local models** (about 9 billion parameters or fewer), Chat uses a shorter version of its instructions and a shorter tool list up front, so it answers faster and chooses tools better.
- **Larger and API models** get the full instructions.
- **Your selected model is never changed.**
- **The instructions are ordered so providers can reuse the cached start of the prompt.** The clock, which changes every minute, now comes last.

## A record of every Chat answer

Each Chat answer saves a run record on its turn:
- which path it took (a direct answer, search, research, files or memory)
- how big each part of its context was
- every tool call and its outcome
- the pages read and cited
- why it stopped, and the tokens used

The record keeps references and sizes only: never the prompt, the reply or the model's reasoning.

## Verification

- **Focused tests run the real Chat loop** with a scripted model through:
  - a simple question
  - current information
  - multistep research, including an invented link being corrected
  - a follow-up citing an earlier page
  - a file explanation
  - running out of budget
- **They also check** the model profiles, the prompt order and the saved run record. The loop's own tests and the Chat boundary tests pass too.
- **Needs your test with real models in Chat:** a current-events question, a comparison that needs several sources, and a follow-up about one of the sources.
