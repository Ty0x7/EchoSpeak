# EchoSpeak 11.10.10 — Plans for code, APIs for chat, and an Echo that checks in

> **Status:** source release on `claude/agents-and-checkins`. The owner builds, installs, tests and publishes it.

Echo Code now knows Codex and Claude Code are signed in and lists every model your plan offers. Chat gains ChatGPT and Claude by API key, and Settings › Connections adds one-click apps with logos, 10 of them new. Echo can now come to you about things that need you.

## Plans for code, APIs for chat

- **Echo Code recognizes your coding agents.** It used to know an agent was connected only through a live session, and sessions stop on every restart. So it said "Connect Codex" and listed no models even while Codex and Claude Code were signed in.
  - Echo now remembers each agent's sign-in, plan and models (never a password or token). The picker shows "Codex · Plus plan" or "Claude Code · Pro plan" right away.
  - Echo re-checks in the background when the status is more than ten minutes old.
- **Sending just works once you're signed in.** Echo picks up your latest session or creates the isolated worktree session, then connects and sends. You confirm once per project and agent that you trust it there.
- **Every model your plan offers.**
  - Codex lists all the models its own app-server reports for your account, with descriptions. Internal hidden ones are left out.
  - Claude Code lists its documented choices: Default (Opus on Pro and Max), Opus, Sonnet, Haiku, Opus-plan/Sonnet-build, the 1M-context versions and Fable. The ones that bill usage credits instead of your plan say so. You can also type a full model name.
- **Sign-in stays put.** Status survives restarts. Sign in is offered only after a check shows an agent is signed out, so it never starts a second login over a working one.
- **The rule, enforced.**
  - In Echo Code, ChatGPT models run in **Codex** and Claude models in **Claude Code**, each in its own harness with your plan. Echo itself uses a model on this PC.
  - API-key models are for **Chat**, where Echo's own harness calls them. The backend refuses an API-key model in an Echo Code conversation, whatever picked it.
  - The old "Claude Agent" (Agent SDK with an API key) is removed from Echo Code.
- **Chat has ChatGPT and Claude.** The model picker's rail is Echo, ChatGPT and Claude.
  - Without a key, choosing ChatGPT or Claude shows a short panel to paste one. It's billed to your API account, not your plan, and stored encrypted.

## Connect apps in one click

- **Add apps.** Settings › Connections opens with every app EchoSpeak can connect, shown with its logo, what it does, Official or Community, and its live status. You can search it and filter by kind of work.
- **Connect shows what you're approving** (steps, cautions, any field it needs), then sets the app up the reviewed way. For apps with browser sign-in, it opens the app's own sign-in page. **Disconnect** signs out and forgets the app.
- **10 new apps:** Todoist, Zapier, Airtable, Canva, monday.com, Sentry, Vercel, Supabase, Hugging Face and Context7. Each is the app maker's own server, checked live before adding. Zapier alone reaches thousands of other apps.
- **Notion, Linear and Jira/Confluence connect now.** Their sign-in was marked "not supported yet", though EchoSpeak could already do it.

## Echo checks in

- **"What needs me"** is on by default and uses no model. Echo tells you about:
  - approvals and questions waiting
  - tasks that stopped, got stuck or failed
  - messages that may not have arrived
  - routines that failed
  - apps that need you to sign in again or keep failing
  - Codex or Claude Code signed out
  - replies failing with model or API errors

  It posts in the **Check-ins with Echo** chat, where you can reply, and as a notification, plus Discord or Telegram if you pick them. Each thing is announced once, and nothing goes out in quiet hours (10 PM to 8 AM by default) or after Stop everything.
- **"Also friendly check-ins"** lets Echo write a short note every few hours from what it knows, mention what's coming up, follow up on what you're working on, or just ask what's up. It stays quiet when there's nothing worth saying and never interrupts while you're chatting.
  - The earlier Heartbeat switch did nothing: it needed two settings the app never set. That's fixed.
- Settings › Automations › **Echo checks in** sets the mode, how often, quiet hours and channels.
