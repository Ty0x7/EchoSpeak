# EchoSpeak 11.10.0

Echo now knows what it is and what it can use right now. You can queue or steer while it works, and it can send read-only research workers. Always allow and Autonomous mode cut down approvals without unlocking risky actions. This release also fixes a permissions bypass in Echo's own file and terminal tools.

## Security
* Settings > Permissions now applies to Echo's built-in file editing and terminal tools. Before, they ignored those switches.
* Always allow grants only apply to chats in the app, never to Discord or routines.
* Destructive commands wrapped in cmd /c, pwsh -c, node -e or python -c now ask first.
* Results from connected-app actions count as outside content.

## Working with Echo
* Self-knowledge: the real version, the app, the OS, and a list of what's on and off.
* Blocked apps replaces the Allowed apps whitelist.
* Always allow, and an Autonomous approval mode that holds risky actions for you.
* Queue follow-ups and steer a running task. Stop pauses the queue, even across a restart.
* Research workers (off by default), with a grace turn to report findings.
* A refusal circuit breaker, so Echo stops working around a "no".

## Learning
* Lessons are tested against a random holdout.
* The Learning tab is redesigned.
* Worker runs and refused actions no longer distort track records.
