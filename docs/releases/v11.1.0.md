# EchoSpeak 11.1.0

A new light look, now the default, with the classic dark theme one click away. Setup also opens in its own window. Everything from 11.0.0, including learning from verified experience, carries forward.

## Light and dark

- **Light theme, the new default.** White surfaces, navy text, light blue edges and a blue accent:
  - blue gradient buttons for the main actions;
  - white message cards with a blue edge;
  - small uppercase section labels;
  - outlined tabs in the right panel.
- **Echo glows.** In light mode Echo has a blue outer ring, and in voice mode a large blue glow behind him. In dark mode the glow is white.
- **Jarvis and Glados** are blue in light mode and black in dark mode.
- **Dark theme unchanged.** The black theme looks as it always has.
- **Choose your look** in **Settings › General › Appearance**, or on the last step of setup:
  - **Light**
  - **Dark**
  - **Match system**, which follows Windows.

  The choice applies to every EchoSpeak window at once.
- Code blocks, errors and warnings use colours that read well on white.

## Setup

- **Setup opens in its own window.** Before, choosing **Open setup** in Settings drew setup inside the Settings window. On first launch the main window opens the setup window, and your first chat opens when setup finishes.
- **A slimmer header.** The title, steps and **Set up later** now sit in one row.

## Requirements

Same as 11.0.0. No settings or data migration. Your theme choice is stored on this device.

## Validation

- **Automated checks:** frontend type checks and 116 unit tests, 15 desktop contract tests (including the setup window and theme handling), and the production build.
- **Browser walkthrough in both themes:**
  - chat and voice;
  - the right panel;
  - every sidebar page and dialog;
  - Settings;
  - setup.
- **Needs release-machine testing:** the setup window and the first-run flow in the installed app.
