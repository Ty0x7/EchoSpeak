# EchoSpeak 11.12.0 — Quieter, clearer, and easier to follow

> **Status:** source release on `claude/v11.12`, built on 11.11.8. The owner builds, installs, tests and publishes it.

## What you'll notice

- **Work reads like Claude and ChatGPT.**
  - While Echo works, you see the thinking box and each step as a plain line, with the current one gently shimmering.
  - When the answer arrives, the work folds into one line, like "Worked for 42s · Read 3 files · Ran 2 commands". Click it to see everything.
  - No more boxes around every step.
- **The chat follows along.** New content stays in view, including what appears below the thinking box. Scroll up to read and it stays put; a small ↓ button brings you back.
- **Reasoning effort in Code,** for Echo native, Codex and Claude Code. Each shows only the levels the chosen model supports.
- **A richer Workspace details panel** (title bar):
  - environment: computer, project, branch and runtime
  - how full the conversation's context is
  - outputs
  - changes, as +/− lines and pull requests
  - servers and scripts
- **A wider sidebar** that shows which conversations are working.

## Fixes

- **Deleting a chat keeps you where you were.** It moves to the newest chat in the same section, or to the new-chat screen, and deleted chats no longer come back.
- **Agents opens the conversation you left,** or a simple "New agent" screen instead of repeating the sidebar's roster.
- **Projects without Git no longer say "Opening project…" forever.**
- **Code's "Files & sessions" button is gone.**

## Coding agents and their rules

- **Claude Code** runs your own, unmodified install with your own sign-in, which Anthropic allows. EchoSpeak never reads or passes credentials.
- **Codex** uses OpenAI's documented app-server integration.
- **Logos:** the Claude and OpenAI logos are no longer used as icons (Anthropic requires permission for logo use); plain names stay.
- **For you:** if you distribute EchoSpeak commercially, confirm with Anthropic whether its Commercial Terms apply. Details are in the [report](../research/interface-11-12.md#4-following-claudes-and-openais-rules-request-4).

## Verification

- **Web:** a new `activity.test.tsx` (6 tests) and updated model and layout tests. 160 web tests pass across the changed folders, and the typecheck is clean.
- **Backend:** effort reaches Codex and Claude Code through their own controls. 90 tests pass for the touched parts.
- **Browser:** checked in the dev build with a scripted model:
  - activity folding
  - following and jump to latest
  - deletes
  - Agents reopening
  - Code's effort control
  - the sidebar's "Working" indicator

From `apps/desktop`, build the installer with:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/release-windows.ps1
```

Install and test it. After reviewing and merging, publish the exact tested build with `scripts/release-windows.ps1 -SkipBuild -Publish`.
