# EchoSpeak 11.11.6 — Echo learns as it works

> **Status:** source release on `claude/autonomous-learning`, built on 11.11.5. The owner builds, installs, tests and publishes it.

Echo now learns from ordinary work in Chat, Agents and Code, with whichever model you use, and you no longer have to manage it. The Learning page has left the navigation. A switch in Settings › Memory and diagnostics in Settings › Advanced are all that remain.

## Learning that runs itself

- **No routine approvals.** Lessons from checked work, including work that read web pages, are tried automatically. Only a few risky kinds still wait for you:
  - lessons that name sites or say which sources to trust
  - lessons about sending or posting things
  - lessons from work that changed tests or EchoSpeak's own files

  Anything nobody reviews is set aside after 30 days.
- **Just say how it went.** "That worked" or "that's wrong" in your next message counts as feedback, the same as the buttons, which still win.
- **Chat actually uses what it learned.** Before, Chat picked lessons but never showed them to the model.
- **Proven lessons are shared carefully.** A strategy proven in Echo's work can help Chat, and the other way round. Its results there are tracked separately, and it stops being shared if it doesn't help.
- **Project know-how stays in its project.**
- **Facts about you stay in memory,** not in lessons.
- **Reviews go where they teach most:** checks that missed something, and recoveries from failing tests, are reviewed before routine successes. They still run only when no chat is running, within the daily limit.

## Simpler settings

- **Settings › Memory:** one switch, "Learn from experience".
- **Settings › Advanced › Learning:**
  - what Echo learned, and whether it helps
  - anything that needs your review
  - pause per agent
  - **Reset learning** (your memory isn't touched)

## Security

- **The in-app updater's ZIP handling is patched.** The release check flagged a critical advisory in the `zip` library the updater uses on Windows to unpack updates (GHSA-m665-v7pm-7grj). The desktop shell now uses Tauri 2.12.4 and its updater plugin 2.14.1, which bring the fixed `zip` 9.1.3. The release's dependency check reports no new advisories.

## Verification

- **New: `tests/test_autonomous_learning.py` (10 tests).** The real harness with scripted models. They cover:
  - the full lifecycle from ordinary use, with no approvals
  - Chat reading its lessons
  - risk-based curation
  - feedback from your next message
  - sharing and its switch-off
  - project scope
  - review priority
  - reset
- **The existing tests for the changed learning, runtime and Chat code pass.** One expectation was deliberately updated: web-learned generic lessons are now tried instead of waiting.
- **Web:** the Learning page and navigation tests and the typecheck pass. In the dev build, the new settings and diagnostics were checked in the browser.
- **Needs your test on a real model:** see the [report](../research/autonomous-learning.md#5-model-dependent-or-needing-your-live-test).


Install and test it. After reviewing and merging, publish the exact tested build with `scripts/release-windows.ps1 -SkipBuild -Publish`.
