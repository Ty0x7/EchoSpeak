# EchoSpeak 11.11.8 — Code is a coding assistant

> **Status:** source release on `claude/native-code`, built on 11.11.7. The owner builds, installs, tests and publishes it.

Native Echo Code no longer runs as Echo the agent. The model you pick answers as itself, as a coding assistant, working in your project with an engineering workflow. Chat and Agents work as before, and all three still share EchoSpeak's harness, safety and learning.

## A proper coding environment

- **The model, not Echo.** Code messages come from the model you picked, named after it, with no persona, team roster or delegation.
- **Engineering tools only.** Files, terminal, docs search, memory and skills. Reminders, media, shopping, live cards, desktop control and agent work are gone from Code. On small local models, the essentials are listed first.
- **A coding workflow:** understand → inspect → plan when needed → edit → run → verify → adapt → report.
  - Every Code prompt includes your project's instructions, git status and git rules.
  - It doesn't commit or push unless you ask.
- **Honest progress.** Steps read "Read …", "Edited …", "Ran `pytest`" with the test counts. A failing run now says "Ran", not "Running". Under the answer, the 11.11.5 checks say whether the work is verified.
- **Learns as Code.** Code keeps its own learning record and can use Echo's proven coding lessons, with their effect measured.

## Unchanged

- **Models in Code:** a model on this PC. ChatGPT runs in Codex and Claude in Claude Code with your plans; API-key models are for Chat.
- **Codex, Claude Code and ACP sessions** are untouched.
- **Agents** are still Echo and your agents; Chat is still Chat.

## Verification

- **New: `tests/test_native_code.py` (6 tests).** Environment separation; Code's tools and prompt; an end-to-end native Code run (failing test → fix → passing test, exactly 4 model calls); Chat and Agents unchanged; the provider rule; lesson transfer.
- **The existing tests for every changed part pass (323),** including Echo Code's.
