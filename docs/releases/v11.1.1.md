# EchoSpeak 11.1.1

A fix for EchoSpeak not starting after updating to 11.1.0, plus clearer text in the light theme. Everything from 11.1.0 carries forward.

## Fixes

- **EchoSpeak starts again after an update.** On some PCs, 11.1.0 stopped at "The installed backend could not load: … cannot import name 'Runnable'".
  - The cause was files left behind by older versions. The installer added and replaced files but never removed old ones, and an outdated module from an earlier release broke the new backend.
  - Every install and update now starts from a clean backend folder.
  - Your chats, settings, memories and agents are kept, because they live in a separate folder.
- **Bolder text in the light theme.** Text uses a heavier weight on white, and hints, timestamps and labels are a shade darker, so everything reads more clearly. The dark theme is unchanged.

## If EchoSpeak shows the error

Choose **Get complete installer** on the error screen, or download 11.1.1 from the releases page, and run it. The new installer clears the old files itself.

## Requirements

Same as 11.1.0. No data migration.

## Validation

- **The cause was reproduced and isolated.** The 11.1.0 backend failed in the installed folder but passed in a fresh build. Adding the old folders back one half at a time narrowed the failure to a single leftover module, `backports/zstd`.
- **Automated checks:**
  - 16 desktop contract tests, including one for the clean-install step;
  - frontend type checks and 116 unit tests;
  - the production build.
