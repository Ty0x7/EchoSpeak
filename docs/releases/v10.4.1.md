# EchoSpeak 10.4.1

Fix cloud chat failures after parallel tool calls. Streamed calls without an index now stay separate by their provider IDs, preserving each name, arguments and Gemini thought signature instead of combining multiple tools into an invalid follow-up request.

- Correct the shared OpenAI-compatible stream parser used by Gemini, OpenAI and Grok while preserving indexed, fragmented streams.
- Reject ambiguous argument fragments instead of assigning them to an unknown tool.
- Keep the minimum supported thinking level for Gemini 2.5 Pro when Think is off, including background/review requests.
- Strengthen **Settings › Models › Test response** for Gemini, OpenAI, Claude and Grok: check two harmless test calls, return their synthetic results and require a final response. No real files, commands, media or external tools run.
- Keep catalog access separate from a working chat/tool check.

Validation: focused provider/stream/readiness regression checks cover all four adapters. A real Gemini 3.5 Flash check completed the two-tool round-trip and final response. Other providers' real accounts, billing and model access remain dependent on their configured credentials. The Windows installer must be rebuilt to apply this patch to installed copies.
