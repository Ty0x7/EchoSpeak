# EchoSpeak 11.2.0

Better memory, cleaner pages, a richer artifact library and viewer, and better-shaped answers. Everything from 11.1.2 carries forward.

## What's new

### Memory that keeps what matters

- **No more chat logs saved as memories.** EchoSpeak was copying every message and reply into memory, even though the setting for that was off. Now it saves only lasting facts. Your chats are still kept and searchable as before.
- **Better facts.** Agents save one short fact at a time, like "Prefers short answers." They don't save reminders, questions, or things that only matter in the current chat.
- **Facts that change stay current.** When your city, job or similar changes, the new fact replaces the old one instead of both being kept.
- **No duplicates.** A fact that's already saved in other words isn't saved again.
- **Less clutter in each chat.** Your pinned facts come first, followed by the few facts that relate to what you asked. Agents read fewer words and get to the point.
- **Clean up old copies.** In Settings › Memory › Saved memories, choose **Remove chat transcripts** to delete the chat copies older versions saved. Your chats themselves are kept.

### Answers shaped like a good document

- Short questions get short answers.
- Long answers start with the point. They use headings, numbered steps, bullets and tables where those help, and they don't end by repeating themselves.
- Headings, lists and quotes in the chat are easier to read.

### Sidebar

- **New chat** is now the first item in the page list, with a + icon.
- The Projects list at the bottom is gone. Open **Projects** from the page list instead. Every chat, including chats in a project, is listed under **Chats**.
- The collapse arrow sits next to the search box.

### Pages

- Projects, Artifacts and Routines are shown as rows, like Group chats.
- **Projects:** start a new chat in a project, or remove a project, right from its row.
- **Routines:** turn a routine on or off and run it from its row. Choose the row to edit it.

### Artifacts

- **A real library.** Search your artifacts and filter them by type (apps, documents, code, diagrams and images). They're grouped by Today, Previous 7 days and Earlier. Each row shows a preview line, the type and when it was last changed, and you can delete from the row.
- **A cleaner viewer.**
  - Switch between Preview and Code.
  - Copy, download and open the artifact with small icon buttons.
  - **Edit with Echo** is the main action. Select text first to change just that part.
  - Documents appear as a page.
  - Older versions show a **Restore this version** bar.

### Learning

- Numbers and charts come first: tasks graded, proven lessons, a chart of the last 14 days, and a chart of how sure EchoSpeak is that tasks worked.
- Each agent's track record is a single row with a success bar.
- Tool and search-provider reliability is shown as bars.

### Fixes

- **Research panel full screen can be closed again.** In the desktop app, the title bar was covering its close buttons.
- **One close button in Settings.** When Settings is its own window, only the window's close button remains.
- **Research panel buttons are quieter.** Edit notes, Export report and Open original are now plain text actions.

## Requirements

Same as 11.1.2. No data migration. Memories already saved are kept.

## Validation

- Backend: 591 tests, including new tests for memory quality, recall and the prompt's memory section.
- Frontend: type checks, 116 unit tests and the production build. 16 desktop contract tests.
- Checked in the browser in light and dark: the sidebar, each page, the artifact library and viewer, Learning, and the research panel.
