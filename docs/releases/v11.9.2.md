# EchoSpeak 11.9.2

Voice setup is clearer and uses the same controls throughout Settings and first-run setup. Drama-3 is an optional local speech provider; it does not replace your conversation model or agent harness. All combined 11.9.0 work carries forward. A2A architecture expansion is reserved for 11.9.3.

## Voice Settings

* Listening and read-aloud have separate sections. Choose Windows voices, Piper, ElevenLabs or Drama-3, see configuration status and test the selected voice.
* Show only the selected speech provider's configuration. Windows has a voice-name override; Piper has a visible model-path field; ElevenLabs keeps its account voice picker, model and speed.
* Voice preview can be cancelled while preparing as well as while playing, and releases audio URLs when it finishes or closes.
* Setup job completion refreshes saved paths without reopening Settings. Listening installation errors now appear directly in the voice section.

## Optional Drama-3 speech

* Verify a trusted audio.cpp executable for the actual Drama-3 speech loader, rather than checking only that an executable exists.
* Link an existing compatible GGUF without copying it, or explicitly download one of six pinned quantizations with progress, SHA-256 verification, disk-space checks, cancellation and resume.
* Build a pinned compatible audio.cpp source revision from Settings when the Windows C++ toolchain is already installed. The older fork and v0.9.2 binaries lack the required backend. No toolchain, model or GPU driver installs automatically.
* Configure CPU or NVIDIA CUDA, GPU index, CPU expert offload and an optional local reference WAV with its transcript. No automatic emotional tags or persona voice clones are added.
* Use the existing reply speaker button, previews, automatic read-aloud, standard voice conversations and governed project speech artifacts. Native Gemini Live keeps its own audio.
* Native workers run without a visible terminal, inherit no app keys, and release memory after each request. Windows process-tree ownership also covers cancellation and backend exit. Pending speech jobs remain cancelled when a late result arrives.

**Built with Fish Audio.** Drama-3 models use the Fish Audio Community License, including its use and commercial restrictions. Read and accept the linked terms before download or import. The model license and conversion notice accompany managed downloads. EchoSpeak's usual installer contains no Drama weights.

## Startup and first setup

* Existing users keep their completed/skipped setup state and are not sent through onboarding again.
* Voice and creation setup start collapsed and remain optional. The final screen shows the selected voice and its configuration status; a working conversation model remains the check for opening the first chat.
* Normal startup never loads Drama weights or starts its runtime. A missing or broken voice provider does not prevent chat.

## Limits and validation

Drama-3 is experimental and its downloads are approximately 16–24 GiB. Download size does not establish RAM/VRAM fit. CPU operation may be slow, and local conversation models share memory with speech. The release uses bounded WAV requests, unloading between clips; persistent warm-model and PCM streaming playback are not implemented.

The focused backend checks passed **99 tests**, including voice routing, native command construction, readiness, model-family checks, cancellation, Windows worker ownership, download integrity and existing provider/onboarding regressions. Frontend checks passed **153 tests**, TypeScript and the production build; all **16 desktop contract tests** passed. An isolated synthetic browser preview checked both themes at 1280, 960 and 768 pixels, path submission and pending-preview cancellation, with no card overflow or browser errors. Both the backend source startup self-check and a fresh PyInstaller backend's startup self-check passed; the bundled model license and notice were verified.

Real Drama inference, sound quality, native compilation, GPU compatibility and the installed Windows update require owner testing. No paid providers or large model downloads were used during development.
