# EchoSpeak 10.5.0

Tidier lists, clearer model selection and a better-organized Settings. All 10.4.3 installer, chat and voice improvements carry forward.

## Lists

- Group chats, Projects, Artifacts, Routines and Creations open on their first three items. **… Show more** reveals the rest and **Show less** folds them again; nothing is removed or hidden for good.
- The open group chat or project is never folded away: if it's further down, the list opens already expanded.
- Creations in progress were capped at 12 and the rest weren't shown at all. Every running creation is now reachable through Show more.

## Choosing a model

- The chat's provider list is grouped into **On this PC** and **Cloud**.
- Switching provider brings back the model saved for it, even before an API key is added or when its catalog can't be reached. It no longer leaves the model box empty.
- The model box says what's happening instead of showing an empty list: "Loading models…", "Add an API key in Settings" or "No models found".
- llama.cpp is no longer offered in the chat picker, because chats can't run through it. Serve the model with llama-server or LM Studio instead. A chat already set to it still shows it.
- Settings › Models (cloud):
  - One **Model** choice, which shows whether your API key is saved.
  - **Use a custom model ID…** opens the exact-ID field only when you need it. A saved ID the catalog doesn't list opens it automatically, so nothing is lost.
- Provider names match everywhere: OpenAI, Google Gemini, Claude and Grok.
- Fixed a bad context-length choice ("63k", 64358 tokens) in Settings › Models.

## Settings

Advanced now keeps only rarely changed options with no section of their own:

- LM Studio only
- Memory search
- Apps agents may open
- Webhooks
- Agent-to-agent (A2A)
- Folders

Everything else moved next to the feature it controls. Every option keeps its saved value.

- **Voice:** speech-to-text engine, read-aloud voice and cloud voice, beside the Whisper setup.
- **Channels:**
  - Discord access lists and changelog posts join Discord.
  - Mail ports and TLS join Email.
  - Twitter / X and WhatsApp get their own groups.
- **Web search:** search timeout, plus the sports odds key under Live data. The second Brave key field was a duplicate and is gone.
- **Automations:** the heartbeat's prompt sits under the heartbeat switch.
- **Memory & documents:** document search settings sit beside the document list.
- **Memory search:** choices are named for what they are: the private search model on this PC, a local model server, or OpenAI. A model name is asked for only when one is used.
- **Search:** Settings search now finds options by name, for example "twitter", "heartbeat", "whisper" or "api key".
- **Text corrections:** the wake-word and Gemini Live notes now match the 10.4.2 composer, and the name field no longer shows a personal placeholder.
- **Routines:** if Run or the on/off switch fails, the error now shows in the list instead of only inside the editor.

## Requirements

Same as 10.4.3. No new settings; no data migration.

Validation: frontend type checks and unit tests; focused backend tests for provider model lists (including the saved model), cloud catalogs, local provider setup and settings; a browser walkthrough against a fresh local backend for the new lists, the provider picker (grouping, empty states, saved-model restore), Settings › Models and every moved setting, including saving and reading back moved keys. The signed Windows installer, real provider accounts and microphones still need release-machine testing.
