# EchoSpeak 10.0.3

Local models now work on a brand-new PC.

## What's fixed

- **It finds your model app by itself.** On first start, EchoSpeak looks for LM Studio and Ollama on this PC. If one is running with a model loaded, chats use it straight away. No settings needed. If you start LM Studio after EchoSpeak, it is picked up within a few seconds.
- **Switching apps switches the port.** Choosing LM Studio uses its address (`localhost:1234`), and choosing Ollama uses its own (`localhost:11434`). A custom address you typed yourself is kept.
- **The chat's model picker no longer gets stuck.** Picking LM Studio in the chat box loads LM Studio's own models and switches. Before, it reused the previous app's model and address and failed every time.
- **Settings and the chat agree.** Changing the app or model in Settings › Models now also moves the open chat. A chat you deliberately set to a different model keeps it.
- **Clear messages instead of silence.** If an app isn't answering, the chat says so and tells you what to do. Settings › Models shows what is running on this PC, with a **Check again** button and a one-click **Use LM Studio** (or Ollama).
- **Sensible defaults.** A fresh install starts on LM Studio instead of Ollama, and no longer carries a model name that only existed on the developer's PC.

## Requirements

Same as 10.0.0. No new settings.
