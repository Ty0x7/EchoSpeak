# EchoSpeak 11.13.1 — Final sidebar refinement

**Objective → Research → Environment → Verification → Adaptation → Completion.**

The owner's accepted Code layout is retained. This patch restores single-column
navigation and removes the added identity header across the three environments.
It reuses existing routing, search, workbench and stop callbacks.

## Changes

- Chat: **New chat → Projects → Creations → Artifacts**, one full-width row each.
- Agents: **New agent → Group chats → Routines**, one row each. Agent roster,
  conversation lists and responsibilities are unchanged.
- All tabs: Search comes first, followed by Chat/Agents/Code. The sidebar's
  EchoSpeak logo, name and Workspace/team label are removed. Collapse remains
  beside search; the compact rail retains its expand control.
- Code: its existing query state is lifted into the shell so the header search
  filters the same actual inbox. Standalone CodeTree retains its own search.
  Working/Snoozed/Settled and their upward-opening behavior are preserved.
- Footer: pull requests, usage, Stop everything and Settings are equal-sized
  icons in one row. Accessible names and tooltips remain. Stop keeps its existing
  two-click confirmation and visible armed color; its text remains accessible.
  The collapsed rail also retains the utility actions.

## Verification

- TypeScript passed; 35 focused web tests and 16 desktop source contracts passed.
- Actual-component Chromium checks passed: ordered vertical navigation with equal
  left edges, search above tabs, aligned four-button footer, chat/code search,
  agent selection, collapsed rail, themes, 390px width and 560px height.
- Existing bulk/stash/background/model-picker/MCP fixture interactions passed.
- Screenshots in `artifacts/media/sidebar-11.13.1/` are deterministic component
  captures, not installed-app screenshots. Previous 11.13.0 images are preserved.
- Runtime/provider logic is unchanged; no new paid or subscription model prompts
  were sent. Prior live-provider evidence remains in the 11.13.0 technical record.

## Build and test locally

Owner acceptance: open each environment and check its search and vertical
shortcuts; open/close the Code shelves; check the four footer tooltips and
destinations. Stop everything's first click arms its existing confirmation.
Check the installed app's version in Settings after installation.

From the repository root:

```powershell
$env:TMP = Join-Path (Get-Location) '.test-state'
$env:TEMP = $env:TMP
npm.cmd --prefix apps/web run typecheck
npm.cmd --prefix apps/web run test:run -- src/components/sidebarSections.test.ts src/app/environments.test.tsx src/code src/runtimeLayout.test.ts
npm.cmd --prefix apps/desktop test
& .\apps\backend\.venv\Scripts\python.exe scripts/check-code-inbox-ui.py
powershell -NoProfile -ExecutionPolicy Bypass -File .\apps\desktop\scripts\build-windows.ps1 -PythonExecutable .\apps\backend\.venv\Scripts\python.exe
```

production frontend, Rust compilation and NSIS/MSI packaging passed. The compiled

test installers; neither was installed, merged or publicly released.
