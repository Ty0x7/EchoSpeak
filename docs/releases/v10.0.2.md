# EchoSpeak 10.0.2

A tidier layout and better sports cards.

## What's new

- **Pages open where the chat is.** Group chats, Projects, Artifacts and Routines now open in the main area, not inside the sidebar. Close one with the ✕ button or Esc to get your chat back.
- **New right-hand panel.**
  - It has two tabs:
    - **Artifact:** the app or document an agent made.
    - **Activity:** everything the agents did in this chat: terminal commands with their output, file edits and searches.
  - It opens on its own when an artifact is made or a command runs.
  - Drag its edge to resize it, and the width is remembered. The chat always keeps enough room to stay usable.
- **Better sports cards.** Team logos, win-loss records, the winner highlighted, a live badge with the game clock, start times in your time zone, and the venue.
- **A tidy start.** A fresh install always opens with the same clean sidebar. Once you resize or fold a section, your layout is kept. Double-click a divider to go back to the default.

## Requirements

Same as 10.0.0. No new settings.
