# EchoSpeak 10.4.2

Polish chat, voice and saved work while carrying forward the 10.4.1 cloud fixes.

- Add Copy below both prompts and replies, and Read aloud / Stop reading below replies.
- Add Edit and Retry below prompts, including failed sends. Continue before that prompt in a new branch, retaining the original chat. Copy completed context, model binding, project/workspace and group members; do not replay old tools or inherit approval grants. Reject stale/foreign prompt identities and busy history.
- Consolidate Voice into one conversation button. Keep dictation separate for composing text and tuck optional controls into one menu. Remove the separate Live microphone toggle: an accessible Gemini Live model selects native audio; other selected local/cloud models use the existing recognition, chat and speech path.
- Let voice fill the conversation area beside the sidebar, with the new Echo avatar centered and a compact transcript/tool/approval view fading in below. Hide the text composer and temporarily tuck away the shared right panel until returning to chat. Pause speech/microphone without automatically reopening the microphone after the reply.
- Use the new Echo face in voice, companion settings and the floating desktop companion. Share saved appearance settings, add voice avatar sizing and preview idle/listening/thinking/speaking/working states.
- Restyle tool approvals without changing exact arguments, approval identity or permission enforcement.
- Gate Think/effort by the selected model and the adapter's implemented support. Disable unsupported controls; keep always-on reasoners enabled and respect configured local capability overrides.
- Polish the existing artifact workspace: saved-version picker, text/source selection and Edit with Echo, preserving preview/source, download, restore and sandbox boundaries. Ignore stale version loads.
- Generate a concise subject title after a chat's first response, using a bounded additional provider request. Preserve manual names and retain a cleaned fallback if title generation fails or the model requires native Live audio.
- Show a desktop update notice above Settings and move sidebar collapse/expand into an isolated top control.
- Fix read-aloud Stop leaving the playback queue stuck, so another message can immediately be read.

Implementation references: [Claude artifact versions and edits](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them), [integrated voice conversations](https://help.openai.com/en/articles/20001274/), and [Gemma 4 thinking capabilities](https://ai.google.dev/gemma/docs/capabilities/thinking). These patterns extend EchoSpeak's existing chat, right panel, voice transport and avatar.

Validation: focused backend checks cover prompt branching, topic titles, thinking controls and cloud/lean regressions. Frontend checks cover playback interruption, native audio and session/panel continuity. A browser walkthrough with simulated backend/desktop responses checks message actions, branch submission, artifact versions/edit draft, update notification, exact approval arguments, the new avatar and wide/narrow full conversation voice layouts. Real microphone/provider accounts and the signed Windows installer still need release-machine testing; no claim of native audio support for every cloud provider.
