# EchoSpeak 11.10.9 — Your Codex and Claude plans in Echo Code

> **Status:** published as [v11.10.9](https://github.com/Ty0x7/EchoSpeak/releases/tag/v11.10.9) on 27 Oct 2026, after [11.10.8](v11.10.8.md), which it includes.

Echo Code now connects to the Codex app you already have and to your installed Claude Code, each signed in with your own plan and running in its own harness. Settings has a new Coding agents group under Models, and a tidier layout.

## Coding agents

- **Codex connects.** Echo found Codex only on PATH, so the Codex desktop app, which keeps its CLI inside the app, showed as "not found". Echo now finds it in the app, on PATH, or at a path you set, and runs Codex's own app-server with your ChatGPT sign-in.
- **Claude Code with your Claude plan.** This is a new Echo Code runtime that runs your installed, unmodified Claude Code with your own sign-in.
  - Echo passes no API key, never reads your Claude credentials, and keeps only "signed in, plan".
  - Sign-in is Claude Code's own `claude auth login`.
  - Edits stay in the session's isolated worktree, where you can inspect and roll them back.
  - Any command or other action Claude Code would ask about becomes an Echo approval card.
- **Claude Agent** (Agent SDK) stays API-key only, as Anthropic requires for SDK-based products.
- **Settings › Models › Coding agents.** For each agent: status, Check (signed in, which plan, models), Sign in (the vendor's own flow), and a location field if it's installed somewhere unusual.

## Settings, reorganized

Settings looks the same, but some groups moved:

- **Approvals** (ask before risky actions, and the separate reader for outside content) moved from General to Permissions.
- **Research workers** and **step budget** moved from General to Agents.
- **Learning from experience** moved from General to Memory.
- **Connections** has its own page under Capabilities, with apps, skills, MCP servers and A2A (both directions). It used to be a tab inside Advanced.
- **Webhooks** moved to Automations.
- **Advanced** keeps only low-level settings.
- Search finds each setting in its new place, and every section opens at its top.
