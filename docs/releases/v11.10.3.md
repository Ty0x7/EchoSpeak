# EchoSpeak 11.10.3

Echo notices when it's stuck on the screen, can save what it learned as a skill for you to approve, and reads your own instructions file. The terminal on This PC now works as well as the sandbox. 11.10.3 also includes everything in 11.10.2 (reminders and the system tray), which wasn't published on its own.

## Games and apps that draw their own buttons
* In 11.10.1, Echo got stuck on Minecraft's main menu: it tried to click "Singleplayer" by name, then asked a screenshot tool to click it six times.
* Now a failed click by name shows as failed, and it says why: games draw their own buttons, so Echo clicks them at the point it sees on the screenshot.
* The screenshot tools say plainly that they only look and never click.
* If Echo looks at the screen three times without doing anything, or two actions change nothing, it's told to act, try another way (another point, the keyboard), or tell you what's blocking it.

## Skills
* Echo can offer to save steps that worked as a skill, such as how to make a new world in a particular game. Drafts wait in Settings › Skills until you approve them.
* A new **desktop-apps-and-games** skill comes with EchoSpeak: how to work menus and games with the screen, check each step, and recover. Add it from Settings › Skills.
* Settings › Skills also lists skills from the folders other agents use (`.agents`, `.claude`, `.codex`) so you can add them.

## Your own instructions
* EchoSpeak now has a folder in your user folder, `.echospeak`, like Claude Code's `.claude` and Codex's `.codex`.
* Write standing instructions in `.echospeak\AGENTS.md` and every chat follows them.
* An attached project's `AGENTS.md` (or `CLAUDE.md`) is followed too.

## Terminal on This PC
* Echo knows which programs are installed (Python, Node, git, …) and how PowerShell differs from bash.
* With Git for Windows installed, Echo can run bash commands on This PC, the same ones it runs in the sandbox.
* Safety is unchanged: risky commands still ask first, on This PC and in the sandbox.

## Verification
* The backend tests (1287) and web checks pass, including a replay of the Minecraft run.
* Retrying the game with a real model is owner testing: TESTING_GUIDE 4.7–4.10.

## Limits
* A small model can still misjudge where a small button is. Echo now notices and changes approach instead of repeating itself, but its aim depends on the model.
* Echo can't edit `.echospeak\AGENTS.md` itself; that file is yours.
* A skill added from another folder is a copy. Add it again to pick up later edits.
