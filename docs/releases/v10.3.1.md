# EchoSpeak 10.3.1

Cloud model switching now supports OpenAI, Google Gemini, Anthropic Claude and xAI Grok, with live model catalogs, secure API key storage and saved model selections that stay selected.

- Settings loads the provider's full API catalog after a key is saved, supports refresh and custom API model IDs, and labels specialized models separately from chat models. Gemini and Claude catalogs include all pages. Catalog visibility does not guarantee billing, region or model access for an account.
- Claude uses its native Messages API for streaming text, thinking and tool calls. Grok uses xAI's OpenAI-compatible API. OpenAI reasoning models use the appropriate output-token parameter without unsupported temperature settings.
- Gemini Live models, including `gemini-3.8-live`, use Google's native Live WebSocket API with text input, output transcription in chat, and tool-call/result continuation. This does not add native microphone/audio playback; audio generated by Live is consumed for transcription and can incur audio token charges.
- Gemini tool-call signatures are retained. A custom or saved model is no longer overwritten by the old fixed list. Settings commits are serialized and the composer refreshes after successful saves.
- Key/access, quota and missing-model failures now include provider-specific recovery guidance. Cloud keys remain in the existing credential broker and are masked in settings responses.
- The marketing website adds animated Creations, research and setup stories, interactive previews, scroll progress and pause/reduced-motion controls.

## Testing handoff

Focused offline provider tests, local-provider regressions and frontend type checking were used; no paid API calls were made. Live account testing and Windows installer signing are left to the user. A successful catalog check validates the key and listing endpoint; actual generation remains dependent on the account's model access and quota.
