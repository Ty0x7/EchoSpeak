# EchoSpeak 11.4.0

You can now see what your agent is doing while it works, and it reads real pages before it compares things. Everything from 11.3.0 carries forward.

## What's new

### See each step as it happens

- **A live line under each step.** While a step runs, a second line says what it's doing right now: "10 results · reading the top 2", "Reading rtings.com (1 of 2)", or the latest line from a command in the terminal.
- **A short summary when it finishes.** The step switches to past tense and says what it found: "Searched “budget mic”" with "14 results · read 2 pages", "Read 3,840 words", "Tests: 12 passed", "+24 lines".
- **Steps fold into one line.** Several steps in a row become a single line such as "Searched the web ×2 · Read 3 pages · Checked prices", with the number of steps and the time taken. Click it to see every step. While it's working, the step that's running stays visible underneath.
- **It says what it's doing between steps.** "Looking over the results…", "Checking the output…", "Working out what went wrong…", "Deciding what to do next…". The status pill above the input shows the same words.

### Reads the sources

- **Opens the top results.** For comparisons, prices, reviews and "best X" questions, a web search also opens and reads the top two results, so answers come from real pages and not just search snippets. Each page it reads shows as its own step.
- **Says what it's about to do.** Before a task that takes several steps, the agent opens with one short sentence, such as "I'll compare three mics by checking reviews and current prices.", and then gets started.

## Requirements

Same as 11.3.0. No data migration. Chats saved before 11.4.0 get the grouped line too, but without the per-step summaries.

- Frontend type checks, 121 unit tests and the production build.
