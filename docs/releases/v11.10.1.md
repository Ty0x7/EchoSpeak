# EchoSpeak 11.10.1

Echo finds things better: one Search by meaning setting with a new 100+ language model and sharper document results, and document uploads work again. Clicks land and misses are noticed, Blocked apps hold everywhere, and Echo can't say it saved a file it never wrote.

## Search by meaning
* One card in Settings › Memory & documents. Choose Keywords only, Fast (English), Better (100+ languages, longer text), LM Studio's embedding model, or OpenAI.
* One button downloads what's needed and re-indexes your memories and documents straight away. No restart.
* Sharper results for English documents: a small reranker that now works in the installed app.
* Fixed: uploading a document with document search on failed.

## Reliability on small models
* Screenshots list the buttons Windows names, with exact points to click, and every click reports how much of the screen changed.
* A file Echo says it wrote must have been written; a click that changed nothing says "No visible change on screen".
* Every action records one outcome (ran, failed, no visible effect, refused, denied, held, skipped) that learning and the safety checks read.

## Safety and control
* Blocked apps are refused from the terminal too, not just from Open apps.
* When the Docker sandbox isn't running, commands on this PC ask first (Always allow and Autonomous still cover them).
* "On this PC" in a request means commands run on this PC.
* Research workers run only for deep research or on Ultra, all at once; Settings has Workers one at a time.

## Verification
* Backend suite and web typecheck plus tests pass.
* The new search models were run on their real files on this PC: the multilingual model matched an English and a Spanish note to the same question, and the reranker put the relevant passage first.
* Not yet run: live model sessions and the packaged app. Manual tests are in docs/TESTING_GUIDE.md.
