# EchoSpeak 11.4.1

A fix release: web search and reading web pages work again in the installed app. Everything from 11.4.0 carries forward.

## What's fixed

- **Web search works again.** In 11.4.0, searching from the installed app could fail with "DuckDuckGo package not installed". The app had been built without its search and page-reading parts, so Echo couldn't look anything up or read the top results.
- **The build checks itself.** The installer can no longer be made without web search and page reading. If anything the app needs is missing, the build stops and names it.

## Requirements

Same as 11.4.0. No data migration. Update from Settings › About, or install over the top.

## Validation

- Built the backend bundle with the new check; its self-check imports web search and page reading.
- Backend and frontend tests, the production build, and 16 desktop contract tests.
