# EchoSpeak 11.8.0 (draft)

The harness catches up with what models and protocols shipped this year, keeps what it reads safer, and shows where the time goes. Not released yet: the version number is still 11.7.1 in source.

## What's new

* **Claude's own computer tool.** With a Claude 5 model and Desktop control, Echo uses the computer tool Claude was trained on: 17 actions, including zoom. Every action still runs through Echo's checks (permission, approval, a fresh screenshot, the same screen layout). Settings › Permissions can turn it off to compare. Other models keep Echo's general tool.
* **Desktop control you can turn on in one place.** Turning on Control the desktop now offers to add it to Echo (and other agents), with screenshots.
* **Longer holds for games.** Holds and waits can last 5 seconds (a batch 10); triple-click and sideways scroll are new.
* **Sign in to hosted MCP servers.** Notion, Linear, Atlassian and other hosted servers that need OAuth now have a Sign in button. Your browser opens their page; tokens stay encrypted on this PC and refresh by themselves.
* **MCP Apps.** A tool that ships its own view (charts, forms, viewers) now shows it in the chat, in a sandboxed frame that can reach only what its server declared, and nothing in Private or Offline mode. A view can call only read-only tools of its own server; anything that acts goes through Echo and its approvals.
* **Long MCP tasks.** Renders and exports that take minutes show their progress, and Stop cancels them on the server.
* **A separate reader for outside content.** Email, Discord and connected-app results (optionally web pages too) go first to a reader with no tools. Echo sees only the facts it found, and the chat tells you when content tried to instruct an AI. The Rule of Two still asks before anything leaves your PC: a summary isn't trusted either.
* **Timing.** Activity › Timing shows where a reply's time went: thinking, each tool, waiting for you. Traces hold names, timings and token counts, never message text, and can go to your own OpenTelemetry collector.
* **Long results kept whole.** A tool result too long for the context is saved, and Echo reads the part it needs by searching or by position, instead of losing the middle.
* **Ask other agents.** Add another AI agent (such as a friend's EchoSpeak) in Settings › Advanced › Connections & skills after confirming the fingerprint of the key that signs its card. Echo asks you before each message, and treats replies as outside content. EchoSpeak's own card is now signed.
* **The Echo bench.** `scripts/echo_bench.py` runs ten real tasks through the app and records pass or fail per model and version.

## Under the hood

* LangChain is gone. Tools, memory search and document search run on EchoSpeak's own code: the same tool schemas, the same search results, and indexes that never load with pickle. Memory and document indexes from 11.7 convert once, on first start, without re-embedding.
* One approval system: the unused 9.x approval routes and card are removed.
* One set of screen tools: the shadowed legacy screenshot and vision tools are removed; OCR stays for models that can't see images.
* Inbound A2A now works from other machines: it no longer sits behind the app's API key (it always required its own A2A key).

## Before release

* Run your Minecraft test and `python scripts/echo_bench.py --desktop` with the models you use.
* Run `python scripts/eval_learning.py` to decide whether learning stays on by default.
* Start the installed app once with your existing data and check memory search still finds things (the index converts on that start).

## Validation

Backend tests (963), frontend checks and tests (135) and desktop contract tests (16) pass. The new parts are tested against simulated servers, models and input: two EchoSpeaks pinning and asking each other, a full OAuth sign-in including a refused reply from the wrong issuer, Claude-format computer batches stopping at a failure, and LangChain-format indexes opening through the real memory and document stores. None of it has run with real providers, real MCP servers or your desktop yet.
