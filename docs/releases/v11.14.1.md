# EchoSpeak 11.14.1 — One assistant, one list of conversations

> **Status:** source on branch `agent-first-sessions`, **not merged into `main`** and **not published as a
> release**. A Linux AppImage (sha256 `87f5d75d…a5a1`) was built and installed locally for the owner's acceptance
> testing; the shared backend, the terminal and the desktop all report 11.14.1. No Windows installer was built.

11.14.1 finishes the agent-first milestone of 16–17 November. It acts on the owner's audit of real conversations:
Chat, Code and Agents behaved like three different assistants, Echo guessed about its own app, and the terminal had
no way to move between conversations.

## What changes for you

| Area | Before | Now |
|---|---|---|
| Projects | Attaching a trusted project swapped Echo for a separate engineering assistant: no live data, no research checks, 40 steps | A project **adds** file and terminal tools to Echo; everything else stays, research checks included |
| What agents know | Echo said there was no chat mode and that EchoSpeak "isn't a harness"; Jarvis gave the app version as his model and couldn't see Echo | Every agent is told the full roster, the model writing its replies (never the app version), what EchoSpeak is, and the real commands |
| Terminal | No way to browse or switch conversations without knowing an id | **← on an empty input** opens a session manager: who answers, project, state; search, filters, Enter to resume |
| Desktop | Chat / Agents / Code switch; folders attached as trusted without asking | One conversation list with the terminal's filters (All / Echo / Agents / This project); a header with agent, model, project and approval mode; a trust question when attaching a folder |
| Permissions | A question card could offer "give me permission … and I'll build it" | Question cards can't offer permissions; Echo says what is off and where to turn it on |
| Deliverables | A file that was never written could be recorded as "completed" | Work records say "not delivered", "fallback accepted" or "not where asked", from the tools that ran |
| Code in replies | Described as working without anything running it | Syntax-checked (never executed); labelled "Not run" when nothing ran it |
| Reviewing agent work | Echo read summaries and docs | `agent_sessions` reads the real Claude Code and Codex logs (read-only, credentials redacted) |
| Delegation | An agent in its own conversation had nobody to hand work to | It can hand work to anyone on the roster; a group still delegates within itself |
| Restarts | The terminal kept a dead address after the backend restarted | It reconnects to the restarted backend |
| Default folder | Without a project, agents running from source were pointed at EchoSpeak's own code | Your Documents folder |

## Known gaps

- **The held-out cases H1–H7** and other models were not run for this version.
- **The Linux sandbox's system Python has no pytest,** so EchoSpeak can't verify Python fixes itself on that
  machine (`pacman -S python-pytest`).
- **The desktop has no per-turn marker** of which profile answered; the header names the agent and the project.
