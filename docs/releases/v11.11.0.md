# EchoSpeak 11.11.0 — Chat, Agents and Code

> **Status:** source release on `claude/three-environments`, built on 11.10.10. The owner builds, installs, tests and publishes it.

EchoSpeak is now three environments in one app, with one sidebar: Chat to talk to the model you choose, Agents to message your persistent agents, and Code for your projects and coding sessions.

## Chat: just the model

- **The model you chose answers as itself.** You see its name and maker's mark, for example GPT-5.5, Claude Sonnet 5.5 or a model on your PC, instead of Echo.
- **It runs in Echo's own harness,** with web search, files, the terminal, vision, skills, reminders, your memory and past chats, and the same approvals.
- **No team or orchestration in Chat.** There's no delegation, no team, no research workers and no persona editing.
- **Your older chats are here** and continue this way.

## Agents: your teammates, like contacts

- **Every agent has its own conversation, and that includes Echo.** Open it from the sidebar or the Agents page.
  - Echo is listed first as the coordinator. Specialists follow, most recently messaged first.
  - Each agent shows its last message, and its profile is one click away.
- **Agents message you there.**
  - Echo's check-ins arrive in Echo's own conversation. The old "Check-ins with Echo" chat stays as history.
  - Routine results and reminder chats are listed under Agents › Conversations.
- **Group chats, Routines and Learning live in Agents.**
- **Nothing about how agents work has changed:** delegation, routines, approvals, learning and their safety rules are the same.

## Code: projects you can organize

- **Code's sidebar lists your projects,** each with its Echo, Codex, Claude Code and ACP sessions.
- **Drag an Echo session onto another project to move it,** or use **Move to…**.
  - It moves only into a trusted project, and only between turns.
  - Codex, Claude Code and ACP sessions stay in their project's worktree. They keep their own sign-in, tools and permissions.
- **Sessions whose project was removed** show under Unorganized, so nothing is lost.

## One sidebar

- **A Chat · Agents · Code switcher** sits at the top of the sidebar. In the collapsed sidebar it becomes three icons.
- **Each environment shows only its own pages and lists.**
  - Search still finds everything and opens the result where it lives.
  - EchoSpeak remembers the environment you were in.

## From Chat to an agent

- **Send to an agent** on a Chat reply opens that agent's conversation with the reply quoted as a draft.
  - You edit it and send it.
  - Only what you send reaches the agent. No chat history is copied and no permission changes.

## Also

- **A test no longer depends on Docker.** A coding test that passed only when Docker happened to be running now pins the sandbox state.
