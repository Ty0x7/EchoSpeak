# EchoSpeak 10.0.0

EchoSpeak 10 is the first official release. It brings a new agent runtime, agents and group chats, guided voice setup with a "Hey Echo" wake word, search across past chats, a Docker sandbox by default, and one-click updates from inside the app. There is no version 9.

## Highlights

- **One agent loop for everything.** Chat, voice, Discord, Telegram, routines, and group chats all run on the same lean loop. The model keeps calling tools until the job is done. It doesn't stop after a fixed plan.
- **Agents and group chats.** Echo, Jarvis (research) and Glados (building) can work alone, hand tasks to each other, answer side by side in a group, or hold a short **discussion** that ends with one conclusion.
- **Voice that works out of the box.** Settings › Voice downloads a local Whisper model (75–480 MB), and the mic works with nothing leaving your PC. Turn on **Wake** and say "Hey Echo".
- **Search past chats.** A search box in the sidebar finds any message you or an agent ever wrote, and agents can search old chats too.
- **Sandbox by default.** If Docker is running, commands run in a container. EchoSpeak asks before using the internet from it, deleting project files, or running on your PC itself.
- **Updates in one click.** Settings › About shows "Update to x.y.z" when a new release is out. It downloads the signed installer, verifies it, and restarts on the new version.

## Agents and group chats

- **Group chats finish what they start.** An agent saying "Sure, I'll do that" no longer ends the chat. Agents mark work finished with a summary; if something is still open, the right agent carries on. Every group run ends with **✓ Done: …** or **Stopped: …** and the reason (limits: 4 rounds, a token budget, or agents repeating themselves).
- Every agent turn is its own message, in order. That holds live and after a reload, including handoffs (A → B → A).
- Handoffs are capped at 6 per message, an agent can't bounce a task straight back, and the teammate sees your original message.
- **@all** or several @mentions answer in parallel when they share a model, then the room's lead posts a short summary. Mixed-model groups take turns, so a local server never loads two models.
- **Discussion mode** (group settings › How the group answers): agents take turns, up to 4, 6 or 8 messages. Any agent can end the discussion early by saying DONE once at least two have spoken, and the lead then writes the conclusion.
- Agents have faces that match the website: white Echo, dark teammates, blinking now and then. Scout is now **Jarvis** and Forge is now **Glados**. Existing chats and @mentions keep working.

## Long tasks

- **Honest stop at the step limit.** When an agent runs out of steps it says so, lists what it finished, and shows a **Continue** button. It doesn't present half-done work as finished.
- **Summarize instead of trimming.** Long chats keep a rolling summary of older turns. Long tasks squeeze their earlier steps into a progress note instead of dropping them, and the chat notes "Earlier steps summarized to fit the context window".

## Coding and terminal

- Native coding tools: paged file reading, exact-text edits, file search and find, background processes.
- **Terminal: Auto** (the new default) uses the Docker sandbox when Docker is running, and this PC otherwise. The sandbox is offline until you allow the internet (Settings › Terminal › Internet access: Ask first / Always on / Off).
- One projects folder in every mode: new projects go to `<data folder>\projects`. Projects from older builds are copied in once.

## Channels

- Discord, Telegram, Twitch and Twitter run on the lean loop. Only the owner gets the full toolset, memory and past chats. Other people get look-up tools only: web, weather, sports, time and math.
- Telegram treats people as the owner only when an allow-list is set.

## App

- Faster, calmer start-up: the backend ships as one folder with no console window, a splash shows instantly, and the boot screen shows real progress ("Step X of Y") with Echo's face spinning. The "signal is aborted" error is gone.
- A live status pill above the composer names the agent and what it's doing, with Stop (Esc).
- New Settings: agents, permissions, terminal, voice, web search, memory, automations, channels.
- **Settings › Advanced** holds the less common options, memory and document management, connections and skills, and the companion editor. The old classic settings window is gone; your saved values carry over.
- **Safer with untrusted content.** After an agent reads a web page, email or channel message, it must ask you before it sends anything, saves a memory, or runs commands online, and it never sends your API keys anywhere. The local API also rejects requests from other websites.
- Resizable, collapsible Chats and Projects sections in the sidebar.
- Polish: one motion curve, focus rings everywhere, better contrast (WCAG AA), reduced-motion support.

## Under the hood

- The state store moved from JSON files to SQLite (`phase3/state.db`) with a full-text index of every message. Your existing data is imported on first start, and the JSON files are kept as a backup.
- The legacy pipeline was removed: about 12,700 lines of `core.py` and 15 modules.
- `index.tsx` was split into modules (12.5k → 9k lines).
- An evaluation script runs 20 real prompts against a live model (`apps/backend/scripts/eval_gemma.py`).

## Requirements

Windows 10 or 11 (64-bit). For a local model: LM Studio or Ollama (Gemma 4 E4B recommended). Docker Desktop is optional; it enables the sandbox.
