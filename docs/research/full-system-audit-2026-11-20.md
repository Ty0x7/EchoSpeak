# EchoSpeak full-system audit · 20 November 2026

**Status:** Source engineering and evaluation on Linux. The installed 11.15.0 AppImage remains the build from `e3f8c4c`. Read the [visual summary](../../artifacts/research/full-system-audit-2026-11-20.html) alongside the technical record.

## Summary

Local Qwen completed all eight projects in the paired coding trials under independent tests. Echo’s own verification was unreliable, and the candidate spent more calls. The defensible improvement is narrower: the same saved LT1 run now produces a credited check, identical test commands can rerun after a source edit, empty collections are blocked checks, and independent evaluations use an offline sandbox. The controller now rejects a candidate pytest run that exits without a usable result. A separate held-out trial exposed false attribution of a local action to an unavailable agent.

### Independent review before merge

The judge's disposable copy preserved fixture symlinks. The separate evidence collector still followed a file symlink on the host while building the before and after evidence. It now visits only regular files through directory descriptors with symlink following disabled. A second gap was that inherited or explicit environment settings could turn on networking or choose host execution before any simulated approval was requested. The evaluator now pins its backend directories, loopback model recorder, Bubblewrap and offline terminal settings after applying experiment options. The terminal also rejects a host route from the evaluation backend at launch, independently of the simulated approval response. The terminal's general Bubblewrap environment uses EchoSpeak's configured read-only filesystem and masking rules. The independent Python judge uses a narrower mount set.

Three synthetic tests reproduced the gaps on `2709070`. The updated judge, sandbox, terminal, security policy, zero-billing, verification, controller and learning suites passed 207 checks, including live Bubblewrap tests. One bounded post-review D1 run at 16K confirmed Bubblewrap and terminal networking off in metadata. The fix passed independent verification with 8.37, 9 model calls and zero critical findings. Runtime verification still reported `unverified`. This check establishes that the narrower evaluator can complete a coding case.

The saved 8.55 → 8.11 movement comes from tool execution (6.75 → 5.75) and efficiency (6.79 → 5.84). Completion, security and recovery stayed at 10 each. H1 repetition 2 used 18 calls instead of 13 and replaced the canonical suite with manual assertions after `/usr/bin/python` lacked pytest. Both T1 candidate repeats tried unittest and collected zero. Every paired repetition hit the same missing pytest on the system interpreter. Some runs recovered using `pytest` on `PATH`, and one candidate run installed it online under the old evaluator. The terminal environment and tool choices varied across repetitions. A causal finding about the 16K window or the candidate runtime needs a matched offline interpreter and more repetitions. Preserve the original scores and test-install evidence.
